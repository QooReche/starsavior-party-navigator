# 추천 파티 계산기 가중치 검증 (2026-10-19)

## 0. 조사 한계 (중요)
웹 검색으로 코스모 게이트 보스별·작전 고난도·성간 회랑·플래시 포인트의 "구체 편성 사례"는 거의 못 찾았다(한국어 가이드 대부분 영상/이미지). 오토 전투 AI 동작(수동 의존 스킬, 대기 스킬)을 다룬 글도 못 찾았다. 아래 '오토 규칙'은 대부분 [추정]이다.

## 1. 확인한 사실과 출처
1. 속성 상성 효과 자체는 작다: 피해 +-5%, 효과적중 +-30%, 유리 시 강인도 피해 가능. [확인, 이전 research.md: DB 계산기/나무위키 전투]. 단, 게임조선은 상성으로 강인도를 빨리 깎는 것이 핵심이라 함 [확인, 이전 research.md의 GC https://m.gamechosun.co.kr/news/view.php?no=218882].
2. 적 단일 공격 전열 80%/후열 20%, 디펜더가 있으면 높은 확률로 디펜더 우선 [확인] https://namu.wiki/w/%EC%8A%A4%ED%83%80%EC%84%B8%EC%9D%B4%EB%B9%84%EC%96%B4/%EC%A0%84%ED%88%AC
3. 디펜더 1명이면 후열 보호에 충분, 2명 불필요, 레인저/서포터도 전열 가능 [확인] allclash https://www.allclash.com/the-best-teams-in-star-savior-early-game-star-attribute-specialized/
4. 같은 글의 속성별 팀: 질서 팀 = 루나/아세라(왈츠)/에밀리/세이라 (혼돈 보스용), 혼돈 팀 = 로자리아 또는 리디아 + 에밀리 + 레이시 + 아세라(왈츠) (질서 보스용). 22개 팀 거의 전부 디펜더(에밀리/힐데/하레/페이) 1명 + 아세라(왈츠) 포함 [확인]. 태양(vs 별): 바니 샤를 리더. 5번째 슬롯에 오메가가 매번 들어감(브레이크 스킬 담당으로 보이나 글이 명시 안 함 [추정]).
5. lootbar: PvE 전열 에밀리+힐데, 후열 바니샤를/레이시, 지원 아세라(왈츠). "딜 숫자만 쫓지 말고 균형", 보호막이 원킬 방지에 중요 [확인] https://www.lootbar.com/blog/en/team-building-guide-pve-bosses-progression-star-savior.html . 브레이크 중에는 버프/방깎/궁극기를 몰아 쓰라고 함 [확인].
6. 코스모 게이트 관련 개별 평가(AllClash 티어): 세이라=코스모 게이트 보스 핵심, 키라=코스모 게이트 핵심(단일 딜러), 릴리 보호막=불사왕 모굴루스 핵심 이유, 나루=코스모 게이트 땜빵 [확인, 단 내용이 영어 요약 도구 경유] https://www.allclash.com/best-saviors-in-star-savior-tier-list/
7. oslink(한국어) 티어: T0 레이시/세이라/샤를, T1 다나/카르멘/루나/스마일/아세라, T4 클라리사/클레아/날/안나/스칼렛/마르실르. 오토 관련: "자동 전투에서는 전체 공격 중심 파티가 효율적", "방치형=루나+스마일+샤를+아세라(잡몹)", 아세라는 스킬·필살 모두 전체 공격이라 방치 화력 최상급, 루나 방치 속도 빠름. 내구형(카르멘+레이시+엘리사+샤를)은 고난도 보스용 [확인] https://www.oslink.io/kr/blog/guide/star-savior-tier-list.html
8. 브레이크 스킬: 영상 가이드가 아군 행동게이지+치확/치피 계열(우리 표의 스타피어서로 추정)을 추천, 이유 설명 없음 [확인, 약함] https://vortexgaming.io/postdetail/611090 . 종류별 효과 비교 글은 못 찾음 [없음].
9. 티어표들은 서로 크게 다름(예: AllClash는 아세라(왈츠)를 S+, 카르멘(이터널)을 S+, 루나를 A+로 둠. oslink는 레이시/샤를 T0). 시점·기준 차이 [확인].

## 3. 불일치 원인 가설
1. 티어 출처가 DB 하나(db_tier.json)라 커뮤니티 평가와 다름: DB에서 레이시 2티어, 세이라 2티어(상성 없으면 8점 아래), 샤를(바니) 0.5. 반면 oslink는 레이시·세이라 T0. [추정] 같은 구원자를 시점별로 평가해 순위가 달라짐. 티어 점수 간격(11/10/8/6)에 비해 상성 +3은 "한 티어 + a" 크기라 과도: 4티어 클라리사도 상성이면 2+3=5, 2티어 6점과 비슷.
2. 코스모 게이트 defenderPenalty 3.0이 첫 디펜더에도 걸려 전열 보호가 사라짐(시나리오 1, 4에서 디펜더 0). 실제 가이드는 거의 전부 디펜더 1명 포함(위 사실 3,4,5). 단 NW/GC는 광역 공격 때 디펜더 몸빵이 약하다고도 함.
3. 2파티 순차 최적화(탐욕): 파티1이 좋은 구원자를 독점해 파티2에 핵심(세이라 등)이 밀림.
4. 오토 전용 요소가 점수에 없음(전체 공격 비율, 쿨타임/조건부 스킬 의존).
5. 보스별 핵심 개별 평가(세이라, 키라, 릴리 등)가 반영 안 됨.

## 4. 수정 제안 (구체 수치, 대부분 추정 기반이라 사용자 조정 전제)
A. 디펜더 페널티: defenderPenalty 를 "2번째 디펜더부터"만 -3으로 변경(코드: v -= def_pen * max(0, count-1)). 첫 디펜더는 0. 광역 위주 보스(올베로스 제외 필요 시)에서는 첫 디펜더도 -1 정도. 근거: 사실 2,3,4,5.
B. 상성 비중: 보스 콘텐츠(코스모, 플래시) advantage 3.0 유지, 잡몹 콘텐츠(작전/회랑/일일) advantage 1.5로 낮춤(오토 속도·전체공격이 더 중요, 상성은 피해 5%). 불리 -2.0 -> 보스 -2.5(강인도 피해 불가), 잡몹 -1.0. 근거: 사실 1(상성 작음, 강인도는 보스에서 핵심).
C. 티어 보정: 외부 티어(oslink) 보정값 tierBonus 를 파일에 추가해 +1: 레이시, 세이라, 샤를(바니), -1: 클라리사, 클레아, 안나, 스칼렛, 마르실르. 코스모 전용 +1.5: 세이라, 키라. 모굴루스에서 릴리 +2. 근거: 사실 6,7. 출처 간 불일치가 커서 +-1~1.5 이내로 제한.
D. 오토 모드(체크박스, 기본 켬) 규칙 [추정 중심]:
   - 전체 공격 스킬 비율 가산: 특수기/궁극기가 "적 전체"인 구원자 +1.0(두 스킬 모두면 +1.5). 근거: 사실 7(오토=전체 공격 중심). 데이터는 로컬 sk.tg 로 계산 가능.
   - 아세라(왈츠), 루나, 스마일, 샤를: 위 규칙으로 자연 가산(별도 하드코딩 불필요).
   - 수동 타이밍 의존 스킬(조건부 발동, 쿨타임 대기, 특정 순서로 써야 효과) 구원자: -1.5. 단 어떤 구원자가 해당하는지 확인된 근거는 없음 [없음]. synergy_tags 에 "조건부/수동의존" 태그를 사람이 검수해 붙이는 방식 권장(레이시 HP 회복 기믹, 웨딩 카르멘 보호 의존, 바니샤를 "스킬2 먼저 사용 후 기본기" 같은 순서 의존이 후보이나 오토 AI가 순서를 어떻게 정하는지 미확인).
   - 오토에서는 브레이크 스킬 발동 타이밍이 자동일 가능성 [추정, 확인 못 함]이므로 브레이크 스킬은 "항상 이득인 범용형"(특이점 관측)에 +1 가산하고 직업 보너스형은 현행 유지.
E. 2파티 최적화: 파티1+파티2 점수 합 최대화(상위 풀 12명 안에서 8명 분할 탐색)로 바꾸거나, 최소한 파티1에서 "코스모 전용 핵심(세이라/키라)"을 파티2 후보로 남기는 로직. 코드 변경이 필요해 우선순위 중간.
F. 서포터: supportBonus 2.0 유지(아세라가 거의 전 팀 포함), 서포터 2명 -4 유지. 디펜더 필요 여부는 A로 처리.
G. 브레이크 스킬: 현행 "직업 보너스 인원수" 방식 유지. 근거 부족하므로 UI에 [추정] 표기 유지. 뉴비 범용으로는 스타피어서 추천이 영상 가이드와 일치(약한 근거).
