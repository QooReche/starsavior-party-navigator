# 브레이크 스킬 조사 (2026-10-19)

## 구조 (확실도: 높음, 2개 이상 출처 일치)
- 파티당 브레이크 스킬 1개 장착. 적 강인도(토큰) 브레이크 시 포인트: 일반 1, PVE 보스 3. 3포인트면 다음 자신의 턴에 발동(보스 브레이크는 즉시 충전).
- 발동 시 스킬 효과 + 영역(도메인) 전개(지속 4턴, 루리웹 글). 턴 소모 없음(나무위키 r300). 반격 유발 안 함. 쿨타임 8턴(2025-11 변경, 루리웹 글/starsavior-db). 대미지·힐은 파티 총 ATK/HP 비례.
- 해금/성장: 전술 분석 탭 하단 '브레이크 스킬 레벨업'에서 '브레이크 스킬 지원 계획서' 소모(아포칼립스 상점 관측보고서 탭 하단). 미해금 스킬은 50장으로 해금. 큐브 과부하는 메인 3장 진행 필요(디시 글). 차원 강습은 Lv1 해금에 특수 아이템 필요(starsavior-db).
- 레벨 1~10 비용(계획서): 50/50/100/150/300/400/500/1000/1200/1400 (누계 5150). 피해 +1%/레벨(2~9), Lv10 +2% (총 최대 +10%). 큐브 과부하는 회복 최대 +2%.

## 5종 (출처: starsavior-db 데이터베이스, 3rd party)
| 스킬 | 유형/계수 | 사용 효과 | 노바포스 | 영역(도메인) |
|---|---|---|---|---|
| 특이점 관측 (기본) | 광역 피해, 팀 ATK 70% | - | +4 | 별빛 지평선: 아군 전체 공/방 +20% |
| 스타피어서(Star Piercer) | 광역 피해, 팀 ATK 50% | 아군 전체 행동게이지 +20% | 0 | 전략 사령부: 치확/치피 +10%, 스트라이커/레인저 추가 +10% |
| 큐브 과부하 | 광역 회복, 팀 HP 2% | 오메가 프로토콜: 공격력·효과적중 +15%(2턴) | 0 | 치트 매트릭스: 속도 +10%, 디펜더/서포터 추가 +10% |
| 차원 강습 | 광역 피해, 팀 ATK 50% | - | +4 | CRF 증폭: 공격력 +15%, 강인도 피해 +1 |
| 행성 정화 | 광역 피해(수치 불명) | 적 전체 방어력 감소 1턴(효과저항 무시) | - | 마녀의 축복: 공격력 +10%, 캐스터/어쌔신 추가 +10% |
- 행성 정화: starsavior-db가 '미출시'로 표기(확실도 낮음). 아카라이브 글 제목에 '행성 정화 모션 추가(2025/11/24)'가 있으나 arca.live 는 403이라 본문 못 읽음.
- 속성/상성 연관: 확인된 자료에 없음(클래스 보너스만 있음). 강인도 관련: 차원 강습 도메인 강인도 피해 +1만 확인, 브레이크 스킬 자체가 강인도를 깎는다는 기록은 없음(피해 스킬만 강인도에 영향).
- 한국어 이름 '스타피어서'는 디시 글 표기와 일치(영문 Star Piercer 추정 대응).

## 콘텐츠별 추천 (확실도: 낮음, 근거 빈약)
- 확인된 구체 추천 없음(보스/속성/광역·단일 구분 자료 못 찾음). 커뮤니티 의견: 전부 쓸만함, 스타피어서 Lv1 추천, 큐브 과부하는 Lv10 힐이 좋지만 육성 비용 큼, 차원 강습은 신규라 유망(vortexgaming 가이드). 상황에 맞게 바꿔 쓰라는 권고(디시).
- 추정: 광역 대미지+노바포스 4는 노바 버스트 속도(특이점 관측/차원 강습), 행동게이지+치명은 버스트 딜러 파티(스타피어서), 생존/지속은 큐브 과부하. 이는 추정.
