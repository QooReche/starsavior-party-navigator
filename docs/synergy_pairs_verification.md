## 상위 8쌍 원문 검증 (수동, 원문 줄을 직접 대조)

| # | 쌍 | 판정 | 비고 |
|---|---|---|---|
| 1 | 린(풍월당) → 클라리사 개화 | 맞음 | 린 〈청풍명월〉 치명타 피해 +30%(2턴), 〈환영검무〉 아군 전체 〈도약〉 부여(청풍 상태 조건). 클라리사: 치명타 후 행동게이지 +15%p, 도약 2중첩 이상 피해 +15%. 조건부(청풍 상태 필요), 치명 버프는 자동 지정 1명 |
| 2 | 카르멘(이터널 프로미스) → 페이 | 맞음 | 〈맹약〉 최고 공격력 아군에게 서약, 단일 공격 피격 시 피해 40% 대신 받음+회복(설명문). 페이는 피격 후 회피 시 공격력 중첩. 서약 대상이 페이일 때만 성립(자동 지정) |
| 3 | 크리스텔 → 스칼렛(캔들 스퀘어) | 맞음 | 크리스텔 〈연소〉 적 전체 부여 / 스칼렛 '대상이 연소 보유 시 피해 +15%'. 점화 스택 부여(태양 아군)도 확인. 연소 부여자가 6명이라 범용(강도 2) |
| 4 | 린 → 다나 | 맞음 | 도약 부여 + 다나 '시전자 속성 별' 도약 획득. 치명 버프 쪽은 다나의 치명 조건 확인 |
| 5 | 린 → 로베르타 | 맞음 | 도약 5중첩 시 행동게이지 +20%p, 치명타 시 쿨타임 -1턴 |
| 6 | 린 → 유미나 | 맞음 | 도약 5중첩 시 출혈, 치명타 시 행동게이지 +15%p |
| 7 | 샤를(하트 오브 모나스티르) → 에핀델(블레싱 인 블룸) | 맞음(범용) | 〈축배의 노래〉 아군 전체 공격력 +30%(2턴), 에핀델 공격력 100% 비례. 태양 아군 턴 시작 시 점화 획득도 확인. 단 일반 공격력 버프라 누구에게나 해당(추정 가중 0.6) |
| 8 | 타냐 → 루나(보이저) | 맞음 | 〈뱅뱅 전기톱〉 아군 전체 치명타 확률 +30%(1턴), 루나 치명타 시 통찰 스택. 유형4(행동게이지)는 조건부(브레이크 시 +10%p)라 약함 |

오탐 0/8. 단 1~6은 '조건부 상태' 의존이고 2는 자동 지정 대상 의존이라 실제 파티 효용은 보장되지 않는다.

검증 중 발견해 규칙을 고친 오탐: (a) 스칼렛(리틀 타이런트, 적 강화 해제) → 에핀델(보호막 보유 적 조건)은 오히려 상충이라 연결 삭제, (b) 서약(수호)을 서포터/디펜더에게도 높게 주던 문제(대상은 최고 공격력 아군) 감산, (c) 힐+수호 근거 중복 가산 제거.
