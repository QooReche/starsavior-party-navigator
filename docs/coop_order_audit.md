## 반영

- 공통 `opts.coop_order=stat`을 기본으로 넣었음. MC와 기대값 엔진 모두 상한 전 능력치를 정렬 키로 따로 보관하고, 실제 성공 확률에만 `COOP_CAP`을 적용했음.
- `legacy/alt=capped`는 상한 적용 뒤 정렬과 기존 후보 검사를 재현함. `stat`에서는 누락돼 있던 기본기 액티브·쿨 검사를 추가했음. MC의 생존·본 행동자 제외·기절·수면·브레이크 제외, 첫 성공 반환은 유지했음.
- 예: 앞 슬롯 120%, 뒤 슬롯 180%이면 기본값은 뒤 슬롯이 협공함. `capped`는 둘 다 100%로 정렬해 앞 슬롯이 협공함. 둘 다 180%이면 앞 슬롯이 협공함.
- 기대값 엔진도 같은 근사가 있었음. 후보별 몫 `p × 앞선 후보 전원 실패 확률`은 유지하고 순서·기본기 사용 검사를 맞췄음. `coop_single=false`인 옛 전원 협공 모드는 유지했음.
- `rank_check.apply_rules`는 공통 opts를 읽으므로 새 규칙의 default/legacy/override를 자동으로 적용함. 실행 결과 `assumptions_used`에도 `opts.coop_order`를 추가했음.
- MC 전용 옵션과 공통 옵션은 겹치면 안 된다는 기존 `p3_test.test_ev_engine_opts_untouched`를 따랐음. MC 전용 키를 추가하지 않았으므로 `_EXPECTED_MC_OPTS_KEYS`는 유지했음.
- 고정 해시·골든 시험은 `capped`를 명시했음. 골든·해시 값은 바꾸지 않았음.
