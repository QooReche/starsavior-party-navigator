## 범위·결론

- 빌드 **26610546**의 `SE_POTENTIAL_TEMPLET` **188종**, `POTENTIAL_LEVEL_GROUP_TEMPLET` **220레벨**, 아르카나 **87종**, `ARCANA_UNIQUE_PROMOTE_TEMPLET` **50종**을 계정 보유 여부와 관계없이 대조했음.
- growth는 전후 **188/188종·220/220레벨**을 포함했음. 신규 **25004 끝없는 종착점**도 작업 시작 전부터 들어 있었음. `776f3fc`의 11/12 재추출 반영이 이미 포함된 상태였으므로 다시 추출해도 188이었음. 25004는 능력치 행이 없는 **전투 SE형**이며 growth의 빈 능력치 객체는 누락이 아님.
- 전투 계수는 이전에 **131종**만 레벨이 있었고 **57종**은 빈 객체였음. 빌더가 공개 데이터북 설명(`lv`)이 없으면 `continue`했기 때문임. 그 57종을 표에서 생성했음. 공개 설명에만 의존하지 않으며 능력치형은 전투 스탯만, SE형은 기존 `SeConverter` → `Line` 경로로 연결했음.
- 전투 완전 반영은 **118 → 187종**, **69종 보강**했음(57종 빈 레벨 채움 + 전투 전용 스탯 3종 + 확률 연쇄 8종 + 피격 직전 치명타 피해 감소 1종). **11026 1종은 부분 반영·미확인**임. 해당 강인도는 반영하고 미확인 흡혈은 실행하지 않으며 이름을 미지원 목록에 표시함. 여기서 완전 반영은 모든 표 행에 수치·SE 해석 경로가 있다는 뜻이며 전 종의 실전 결과 검증을 뜻하지 않음.
- 아르카나 고유 효과 **50/50종**은 훈련·의뢰 등 **여정 전용 보너스**로 분류했음. 보유·장착만으로 시뮬에 별도 능력치를 더하지 않음. 여정 결과 능력치와 **습득한 잠재력 ID/레벨**은 내정보를 통해 전투에 반영됨. 고유 효과 50종을 전투 잠재력 188종과 합쳐 세지 않음.
- 신규 아르카나 **7102001 끝나지 않는 춤**, **7106101 빛바랜 꿈**의 고유 효과도 각각 여정 훈련 보너스임. 공개 데이터북은 이벤트 잠재력으로 전자에 **23038 압도적인 공세**, 후자에 **25004 끝없는 종착점**을 안내함. 두 잠재력은 이미 growth에 있었고 현재 전투 경로도 지원함. **개별 이벤트→보상 ID 연결은 아래의 미확인 경계를 따름.**
