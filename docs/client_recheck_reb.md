## 확인한 동작과 변경

### 연쇄 피해

`AddDamage.cs` 로그와 `NSETT_SELF/TARGET`, `NST_RATE_DAMAGE_UP`, `NST_RATE_DAMAGE_UP_BREAK`로 생성·계산 함수를 대응했음. 새 6097–6100에서도 피해 증가, 대상 직업/속성 피해 증가, 브레이크 피해 증가를 합산함. 직업/속성 항은 17510–17542에서 확인했음. 스킬 피해 증가를 시전자에게 귀속하는 기존 스위치는 유지했음.

새 4666–4706은 `ADT_FIXED_TRUE`, `ADT_STAT_TRUE`, `ADT_NORMAL`을 구분함. 일반 연쇄는 기존 배율 경로를 유지하지만 `ADT_STAT_TRUE`는 기본 배율을 건너뜀. 이 문서는 일반 연쇄의 피해 증가 항만 같다고 판정했음. 별도 피해 유형의 표→공개 효과 문구 연결과 엔진 지원 여부는 미확인으로 남겼고, 모든 연쇄 유형이 같다는 주장은 하지 않았음.

### 노바

`NovaForceUp/Down`(4984–4992), 팀 풀 증감(1258–1273), 상수 로더(NT 29656–29657)를 연결했음. 기존 문서에 없다고 적힌 상수 원본은 현 `tables/Plain/CLIENT_CONST_TEMPLET.json:116–119`에 있으며 `MaxNovaForceValue=12`, `UseNovaForceValue=4`임. 따라서 상한 12를 새 스위치로 반영했음. 양 진영과 비교용 개인 풀에 적용하며 증가 때만 상한을 자름. 소비 비용 4와 감소 하한 0은 유지했음.

버스트 레벨·슬롯을 검사해 슬롯 SE를 가져오는 16619–16628과 스킬 SE에 병합하는 2600–2607은 옛 구조와 같았음. manual/heal 공통 적용, auto 사용 여부에 관한 기존 운영 정책은 유지했음.

### 도발·적 쿨·스폰

버프 생성 때 전역 턴을 버프 인스턴스에 저장(5790·4840–4845)하며, 3978은 해당 턴과 적용 시점을 보고 차감을 제외함. 4565–4583의 예외 목록에는 SKILL_START·TURN_START·AFTER_SPAWN·WAVE_START·BATTLE_START가 있고 SKILL_END는 없음. 따라서 현재 행동 중 받은 SKILL_END 도발의 차감 제외는 유지했음. 새 갱신 제외 목록(4433–4435·3978)은 광범위한 버프 시계 개선이며 이 도발 스위치로 전체 시계 동등성을 주장하지 않았음.

반면 자기 턴 종료 함수는 실제로 바뀌었음. 옛 1846–1848의 순서는 버프 차감 → 쿨 차감 → TURN_END였으나, 새 2015–2021은 TURN_END → 버프 차감 → 쿨 차감임. 생존한 자기 행동자만 호출하는 13541–13544와 모든 스킬의 양수 쿨을 1 줄이는 3578–3590도 확인했음. `enemy_cd_native=true`·`enemy_cd_tick=turn_end`에서 새 순서를 적용했음. legacy는 기존 엔진의 쿨 → TURN_END → 버프 차감을 복원하며, 3월판 전체 순서의 재현은 아님. 시작 쿨 부풀리기 비교 옵션과 아군 시작 차감은 그대로 유지했음.

스폰의 AllSkillAvailable·SpecialSkillAvailable·HyperSkillAvailable 로더(NT 37379–37381·41509–41511)와 실제 초기화(1940–1986)를 연결했음. 보스 등급 폴백·전체 배치 수량·공개 배치 데이터 최신성은 이번 코드 대응 확인과 구분했음.

### 자동 선택·턴 제한

`AutoSkillController.cs`, Silence, NSI_SKILL_1_ATTACK, NST_ACTIVE/REACT와 규칙1/1001 상수로 대응했음. 조건에 맞는 첫 행, 사용 가능 스킬 순회, 대상이 없을 때 실패, 확률 필터 실패/빈 결과 시 후보 유지, 후보 한 명이면 중단하는 경로는 같았음. 규칙1은 무적 제외→보스→정예→유리 상성(없으면 불리하지 않은 상성)→HP비율 최저→최대HP 최저이고, 1001은 전열80%→디펜더80%임. 기존 무적 제외 생략·문구 근사·미지원 신규 필터의 완전성은 별도 한계로 남김.

전역 턴은 선택 때 +1(13460–13463), 제한 초과 시 중단(788–794)함. 추가 턴도 같은 선택 경로임. 새 NKC 67617–67618은 일반 레이드 남은 턴 `제한 - 전역 턴 + 1`을 유지함. 새 별도 적 행동 제한(638–668·NKC 67622–67625)을 이 규칙의 actions와 혼동하지 않았음.

### 반격

`SkillHitHistory.cs`의 한국어 불발 로그, `SAT_ATTACK`, `NST_RATE_REVENGE_ATTACK`, `Blackboard.cs`와 `RevengeAttack` 호출로 대응했음. 옛 12068은 판정할 때의 반격 스탯으로 추첨했지만 새 7857은 유효 타격 기록에 당시 확률을 저장함. 새 11627–11638은 현재 스탯이 0 이하면 취소하고, 양수일 때 저장된 확률로 추첨함. 피격 후 확률이 25%→100%가 돼도 해당 타격은 25%로 판정하며, 100%→0%면 취소하는 경계가 생김.

엔진도 양수 피해 기록 때 확률을 함께 저장하고 반격 판정 때 현재 확률 유무를 확인하게 했음. 사망·브레이크·기본기 쿨·행동 불가·같은 편 제외, 시전별 후보 추첨 후 실행, 행동당 반격 중복 방지와 queue 순서는 유지했음. 기존 엔진의 한 시전·대상 단위 집계는 클라의 세부 타격 이벤트 전체를 재현한다는 뜻이 아님.
