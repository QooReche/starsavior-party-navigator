# 훑기 1판 재사용 측정 — 2026-11-22

«조금 돌려 보고 일찍 거르기» 설계의 추천 (가)만 넣었음. 예선 1차가 훑기 1판을 0번째 판으로 다시 쓰고, run_offset 1 부터 7판만 더 돌림.
(나) 보수적 순차 탈락은 넣지 않음. 쉬운 스테이지에서 몇 초 아끼는 데 비해 오탈락 위험과 복잡도가 맞지 않음(사용자 결정).

## 동일성(시험)

- `tests/screen_merge_test.py` `test_scan_reuse`: 스테이지 4곳 × 팀 4개 = 16건을 봄(재점화·N턴 클리어 포함). 셋 다 같았음.
  - 묶음 훑기 1판의 요약이 raw 를 받아도 그대로임.
  - 훑기 1판의 원시값 = 예선 8판의 0번째 판.
  - 1판 + 7판(merge_raw)의 요약·raw = 8판 한 번.
  - 대조군: 시드를 +1 한 훑기를 이으면 16건 중 14건이 달라짐.
- 일부러 깨뜨려 보기: 세 경우 모두 시험이 실패했음.
  - run_offset 0 → 판 수 확인에서 거부
  - merge_raw 빼기 → 16건 모두 다름
  - 훑기 시드 +1 → 다름
  - 화면 쪽에서 1차 재사용을 끄면 `tests/fullscreen_test.js` 가 실패함.
