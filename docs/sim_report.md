# 구원자 화력 지표 / 파티 시뮬레이터 보고서

작성일 2026-10-20. 코드 `sim_damage.py`, 지표 `damage_index.json`, 검증 `validate.py` -> `validation.json`, `tag_check.py` -> `tag_check.json`, `ref_teams.py` -> `ref_teams.json`.
모든 수치는 **장비/아르카나 없음**, Lv200 + 공명 10 + 각인 0 기준의 상대 비교용이다. 인게임 실측값이 아니다.

## 1. 모델

### 1.1 스탯 (databook app.js `sCalc` 재현)
`v = 1레벨 + 레벨업성장x(Lv-1)x배율 (+ Lv200 초과 성장/동기화 점프)`, 공명 flat 가산 후 `v = v + v x 공명%`, 각인(star) 공격력 +2%/단계. 치명 확률 상한 100%, 치명 피해 상한 300%.
고정 조건은 `mode='fixed'`(Lv200, 공명 10, 200 초과분 0). 한계돌파 시나리오는 `mode='normal'` + 레벨/공명 단계 지정. 장비 확장 훅은 `calc_stats(..., gear={'atk':+n,...})`와 `UnitDef.gear_atkp`.

### 1.2 피해식 (research.md 1.5b / databook 계산기)
`기본 = (공x계수 + 생x계수 + 방x계수) x (1+속도/100 x 계수) x 1.85`, 전체 대상 스킬은 `/4`(대상 1명당), `x(1-방어율)`, 방어율 = `방어/(방어+3000)`에서 방어 관통 비율만큼 감소.
`x (1 + 증가합 - 감소합 + 치명확률 x 치명피해)`. 증가합 = 스킬 한정 증가 + 버프 + 속성 스택(vs 속성) + 노바 버스트 15% + 상성 +-5%. 난수는 평균(1.0). 기대 피해이므로 치명은 확률 가중.

### 1.3 전투 루프 (행동 게이지)
게이지 10,000, 필요 틱 = `(10000-게이지)/속도`, 가장 짧은 틱만큼 진행해 도달한 유닛이 행동 후 0. 1턴 = 100틱(속도 100 유닛 1회 행동). N턴 = N x 100틱.
- 스킬 선택: 궁극기 > 특수기 > 기본기 중 쿨타임이 찬 것. 쿨타임은 최대 레벨 값(`cdm` 우선). 시작은 만충(cd턴 뒤 첫 사용).
- 행동 순서: 턴 시작(쿨타임 -1, 턴 시작 효과, 타 유닛 턴 시작 트리거) -> 시전(스킬 시작 효과, 아군 공격 트리거, 피해, 사용 후 효과) -> 턴 종료(버프 지속 감소).
- 적은 속도에 따라 행동하며 지속 피해 틱, 디버프 지속 감소, "적 턴 시작" 트리거만 발생. 적의 공격은 없음.

### 1.4 스킬 줄(`ef`) 해석기
`sk[].ef` 의 문장 약 1,066줄을 `[시점] (조건: 트리거 [키: 값; ...]) 대상에게 효과` 로 파싱해 직접 실행한다(스킬 계수 `cf`, 쿨타임 `cd/cdm`, 노바 `nv`, 노바 버스트 `nb` 포함).

| 구분 | 반영 방식 |
|---|---|
| 스킬 한정 보정 | 피해 증가 / 공격력% / 치명 확률 / 치명 피해 / 방어 관통 (조건 가중) |
| 자버프/아군 버프 | N턴 버프, 무한 중첩 스택(공격력%, 속도%, 치명, 피해 증가, vs 속성, 기본기/특수기/궁극기 피해 증가) |
| 행동 게이지 | 자신/아군/적 증감(%p), 추가 턴 |
| 쿨타임 | 쿨타임 감소 |
| 추가 발동 | 특수기 추가 발동(x N), 아군 공격 트리거로 발동 |
| 연쇄 피해 | 공격력 x N% x 1.85 (방어 적용, 치명/나눗셈 없음) |
| 지속 피해 | `‹턴마다 공격력 x N%›` 및 연소 20% / 출혈 25% / 빙결 15% / 중독 생명력 5%, 스택/지속 반영 |
| 적 디버프 | 방어력% 감소, 속도% 감소 (성공률 0.9 가정) |
| 협공 | 협공 확률 버프(상한 30% = `NST_RATE_CROSS_ATTACK`) -> 아군 공격 후 자신 기본기 추가 시전, `〈강제 협공〉` -> 대상 아군 기본기 추가 시전 (**추정**) |
| 조건 | 스택 수(실수 스택 소프트 비교), 사용 스킬, 추가발동 여부, 대상 보유 효과/약화효과 수, 결과 치명타, HP%, 처치, 시전자 속성/버프 등. 확률 가중 후 곱 |
| 노바 | 특수기/궁극기 `nv` 누적, 4개면 다음 공격 스킬 +15%와 `nb` 의 게이지 증가 (구원자 개인 단위, 팀 공용 여부 미확인) |

해석 못 한 줄: 조건 미해석 40줄(전체의 3.8%, 주로 "내가 피격될 때" 반응 줄), 효과 미해석 3줄. 보호막/회복/해제/교체/무작위 효과는 의도적으로 무시(20+24+4줄).
데이터가 "소비"를 "부여"로 적은 줄(그웬 전기 충격 5회 이상 -> 추가 발동 + 5회 "부여")은 소비로 보정했다(해당 줄의 발동 조건이 5중첩 이상이고 부여 횟수가 같을 때).

### 1.5 지표 시나리오
- 개인 지표: 대상 구원자 + 속성 없는 **더미 딜러 3명**(기본/특수/궁극 순환, 효과 없음). 아군 공격 트리거를 공급하되 버프는 주지 않는다. 기준 적 방어 1,400, HP 무한, 속도 100, 상성 0.
- 단일 = 적 1체, 광역 = 적 3체(총합). 전체 스킬은 1체에 cf/4, 3체에 3 x cf/4.
- `ally_dmg_gain_pct`: 구원자 1명 + 더미 3명에서 더미 3명 피해가 "더미 4명" 기준 대비 몇 % 늘어나는가(아군 버프 가치).
- 점수: `norm_global = 10 x (0.5 x 단일 + 0.5 x 광역) / (SSR 딜러 상위 95% 값 = 9,064)`, 10 상한. `norm_role = 10 x 값 / 같은 역할 최대`. 단일/광역 별도 점수도 제공.
- 파티: `simulate_party(keys, enemies, turns)`; 대표 스테이지 5개(코스모 길레 1~3단계, 플래시 포인트 매니저 그레고리 Ⅰ·Ⅱ; 모두 Lv200/공명10 고정 콘텐츠, 1웨이브)의 적 HP/방어/속도/속성을 `foe_stages.json` 에서 읽어 처치 턴 수를 계산(최대 40턴).

한계: 대상 선정 기준은 "스탯 공격력"(장비 제외)로 가정했다. 실제는 버프 포함 현재 공격력일 수 있고 장비가 크게 영향. 임계점은 불연속이라 장비 포함 시 위치가 달라진다. "돌파"가 각인(별 단계)인지 한계돌파(레벨 상한)인지 글에서 확인 불가 -> 위 표에 둘 다 시험했고 각인 쪽만 현상이 재현됨.

### 3.4 검증 3: 태그(`synergy_tags`)와 파싱 효과의 일치도
| 태그 | 태그 수 | 파싱 일치 | 태그만 있음 |
|---|---|---|---|
| 아군공격력증가 | 8 | 6 | 베라 x2 (무작위 효과 -> 의도적으로 무시) |
| 치명증가 | 5 | 4 | 린 (대상이 "아군(자동 지정)"인 변형 문장, 시뮬은 반영 / 점검 함수 한계) |
| 속도증가 | 11 | 7 | 세이라, 베라 x2, 웨딩 카르멘 |
| 쿨타임감소 | 10 | 8 | 바니 샤를, 루그 |
| 적방어력감소 | 5 | 4 | 화이트펄 루나 (반응 트리거 스킬, 미반영) |
| 적행동게이지감소 | 7 | 7 | - |

파싱에만 있고 태그에 없는 항목은 0건 -> 태그가 파서보다 넓게 잡힌 상태이며 상호 모순은 없다. 파서가 못 잡은 것은 무작위/반응/변형 계열.

## 4. 한계
1. 적의 공격·생존·힐·보호막이 없다. "버티기"는 이 지표 밖이므로 화력 점수 단독으로 파티를 고르면 안 된다.
2. 반응(피격/회피/수호) 트리거 스킬 6개, 변형(교체) 스킬 4개, 무작위 효과(베라 등)는 미반영. 페이(월영 반격·회피 스택), 로베르타, 리디아 변형 등이 영향을 받는다. 규모 추정: 페이는 반격이 적 행동당 최대 0.2회 수준이라 개인 피해 +3% 안팎, 회피 스택 상한 +20% 공격력(상한값).
3. 협공/강제협공/아군 트리거의 세부 규칙(추가 발동도 아군 공격으로 취급, 협공 = 기본기 1회, 대상 = 스탯 공격력 최고)은 추정. 프로페서M·그웬·왈츠 아세라 값은 이 추정과 더미 파트너 3명의 행동 빈도에 민감(`ally_dependent: true` 12명).
4. 브레이크(강인도), 카운터 +10%, 상성에 따른 강인도 변화, 적 피해 감소/면역/패턴, 전투력 보정(`power_penalty`)은 미반영.
5. 장비/아르카나 없음. 실전 화력의 큰 부분이 장비이고, 공격력 최고 아군 선정 같은 불연속 규칙은 장비에 따라 결과가 바뀐다.
6. 어려움 작전은 적 Lv666 이상이라 Lv200 고정 모델로는 직접 비교 불가(코스모/플래시만 비교). 길레 3단계 같은 HP 1M 은 장비 없는 Lv200 로는 비현실적으로 느리다 -> 처치 턴 절대값이 아니라 파티 간 상대 비교에만 쓸 것.
7. 값이 큰 단일 스킬 쏠림(스킬 AI 단순화), 쿨타임 시작 상태, 버프 지속 카운트는 추정.

## 5. 파티 추천 점수에 통합하는 방법 (권장)
1. **구원자 단위 화력 점수**: `damage_index.json` 의 `norm_global`(0~10)을 기본으로 쓰되 콘텐츠별로 `norm_single_global`(보스 단일), `norm_aoe_global`(웨이브/회랑/큐브)을 섞는다. 서포터/디펜더에는 직접 화력 점수보다 `ally_dmg_gain_pct`(버프 가치)를 쓴다.
2. **파티 단위(권장 = 정확)**: 후보 파티마다 `simulate_party(keys, stage_enemies, 10)` 호출(파티당 약 5 ms, 수만 개까지 가능). 정규화는 4딜러 무작위 팀 분위수 사용: `ref_teams.json` 기준 p50 211,795 / p90 306,056 / p95 349,931. `firepower = clamp(10 x total_damage / 349,931, 0, 10)` (95분위 = 10점). 전체 SSR 무작위 팀 기준이면 p95 = 314,659.
3. **파티 단위(근사, 런타임이 가벼울 때)**: `team = sum_i single_dpt_i x (1 + sum_{j!=i} ally_gain_j/100)`. 600팀 시뮬과 Pearson 0.95, Spearman 0.97(단순 합은 0.90/0.96). 협공/트리거 시너지(프로페서M 계열)는 놓치므로 상위 후보는 시뮬로 재계산.
4. **가중**(기존 DB 티어/상성/시너지/기믹 점수와 합산): 화력 항 가중 w_fp = 시간/턴 제한 보스전(코스모, 플래시) 0.30~0.40, 일반 작전/회랑 0.20, 안정 우선(초반 육성) 0.10. 기존 점수 척도가 0~10 이 아니면 파티 후보 집합 안에서 z-score 로 맞춘 뒤 곱한다.
5. **게이트(버티기만 하는 편성 방지)**: 대표 스테이지에서 40턴 내 미처치(`ttk=None`) 또는 10턴 내 처치율 < 50% 이면 감점 또는 제외. 반대로 제한 턴이 있는 콘텐츠는 `ttk <= lt` 를 하드 조건으로.
6. **다타 의존 연계**: 파티 `hits/턴` 합(예: 8 이상)과 `extra_hit_dmg_share`(추가 발동·협공 비중, 4딜덱 42%)를 `stage_gimmicks.json` 의 HIT_STACK_* 기믹과 연결해 감점. 이 지표는 시뮬이 직접 판단하지 못하는 부분이다.
7. 구원자 정보가 바뀌면(`databook_main.json` 갱신) `python -X utf8 -I sim_damage.py index` 로 재생성(약 1초).

## 6. 확장 포인트
- 장비: `calc_stats(gear=...)`, `UnitDef.gear_atkp`, 또는 `DEFAULT_OPTS` 에 `extra_inc` 추가. 아르카나는 `Line` 형식(`[시점] 효과`)으로 만들어 `UnitDef.lines` 에 주입하면 같은 해석기로 처리된다.
- 반응 트리거: 적 공격 이벤트(`act_enemy`)에서 대상 확률을 만들고 `trig` 가 "내가 피격될 때" 인 줄을 평가하면 된다(현재 `Line.kind='unmodeled'` 로 보관됨, 40줄).
- 브레이크: `opts['break_p']` 자리에 강인도 모델 추가, `ab`(강인도 파괴), `nb` 의 강인도 줄 사용.
- 상성/속성 스택: 스테이지 시뮬은 이미 보스 속성 사용. 코스모 게이트 파티 2개 편성은 `simulate_party` 를 2번 부르면 된다.

## 7. 사용법
```
python -X utf8 -I sim_damage.py index                       # damage_index.json 재생성
python -X utf8 -I sim_damage.py unit gwen                   # 개인 지표 상세
python -X utf8 -I sim_damage.py party professor-m,gwen,fei,amora --stages
python -X utf8 -I sim_damage.py stats amora --level 200 --res 10 --star 0
python -X utf8 -I validate.py                               # 검증(약 6분)
```
구원자 키는 `synergy_tags.json` 의 key(예 `gwen`, `bunny-charlotte`, `besta@개화(SSR)`), 한글 이름(동명이인 없으면)도 허용. Python API: `simulate_party(keys, enemies=None, turns=10, opts=None, star=0, stars=None)`, `stage_report(keys)`, `unit_metrics(key)`, `ally_gain(key)`.
