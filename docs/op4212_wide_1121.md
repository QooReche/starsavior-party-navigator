# 작전 42-12 엔진 가정 전수 대조 (2026-11-21)

## 결론

- 이 전투에서 엔진이 실제로 읽은 규칙 151개(전투 중 138·생성 때 13)와 전투 단계별 계산(능력치 변환·리더·적 AI·행동 순서·피해·치명·효과 적중·강인도·브레이크·보호막·회복·해제·스테이지)을 PC 클라 26752678(`decompiled/`, `check_build.py` 불일치 0)과 표(`rebuild_26752678/T`)로 대조했음.
- **클라와 달라서 고친 것 2건**(둘 다 규칙 스위치, legacy 보존):
  1. `mc.unique_id_stack` — IsUniqueID 버프 재부여 때 옛 객체를 지우지 않고 새 객체를 더함. 이 전투의 공허선도자 특수기 〈영혼 구속〉(최대 생명력 −15%)이 해당.
  2. `mc.random_basic_not_self` — 잠재력 «다른 아군 1명에게 25% 확률로 기본기 추가 발동»(별빛의 궤적-EX5호, 그웬·아세라 보유)이 시전자 자신을 고르던 것을 클라대로 자신 제외.
- 작전 42-12(내 정보 1121, 1000판·seed7) 클리어는 **25.0% → 23.9%**(−1.1%p, 전부 2번 규칙). 실제 약 20판 0승과의 차이는 남았음(23.9%에서 20판 전패 확률 약 0.4%). 클라에서 근거를 찾은 나머지 항목은 모두 엔진과 같았고, 클라로 확정할 수 없는 항목은 아래 «남은 것»에 찾아본 범위와 함께 적었음.
- 전투력 차이 보정(wt-power)·아군 오토 스킬 선택(wt-autoskill)은 담당 밖이라 바꾸지 않고 영향만 쟀음.

## 고친 것

### 1. IsUniqueID 버프 객체 누적 (`mc.unique_id_stack`, 기본 client·legacy off)

- 클라: 버프 부여(NKM:4303-4490)는 같은 ID가 있으면 IsUniqueID일 때 UniqueIdStackMax만 검사하고(4331-4336), 부여 뒤 OBF_5497이 IsUniqueID면 옛 객체 제거를 건너뛰며(4505-4518), 새 객체를 목록에 넣음(4520-4528). 능력치는 객체마다 합산됨.
- 표: BI_BELLWETHER_MANE_1(〈영혼 구속〉) IsUniqueID·TurnInfinite·NV_RATE_HP −1500·EffectHitCheck, UniqueIdStackMax 없음(무제한).
- 엔진 전: 같은 이름 1개를 갱신(중첩 1). 후: `data/buff_flags.json` `unique_id`(빌더 `tools/build_buff_flags.py --only unique_id`, 26752678 `T/CLIENT_BUFF_TEMPLET`+`hard/STRING_COMMON`)에 있는 능력치 효과는 객체를 더함. 기존 `independent_stack_limits`의 파사인 3·상쾌한 기분 5와 같은 값이 표에서 나오며, 두 이름은 기존 규칙이 계속 맡음. 지속 피해·지속 회복은 기존 독립 경로, 능력치 없는 표지(확정 다음 턴·불사·카운팅용)와 이름에 «스탯»이 든 범용 보정(코스모·길드 전용 경로)은 이번 범위에서 제외함. 동명 행이 섞인 이름은 표에서 빠짐.
- 해제: «효과 N개 해제»는 객체 단위(기존 dispel_instance), 개수 없는 해제는 전부.
- 이 전투 영향: 0%p. 200판 계측에서 영혼 구속 부여 304회가 모두 대상에게 없던 상태에서 걸렸음(아세라 궁극기·프레이 특수기 해제가 보스 특수기 쿨 3보다 먼저 지움). 표준 육성 영향은 아래 표.
- 시험: `tests/op4212_wide_test.py` UniqueIdStackTest 5건(3회 부여 → 3객체·최대 생명력 −45%, 2개 해제 → 1객체, 전부 해제, legacy 1객체, 비고유 이름 불변). 규칙 검사를 꺼 두는 변이에서 2건 실패 확인 후 원복.

### 2. 잠재력 무작위 기본기 추가 발동의 시전자 (`mc.random_basic_not_self`, 기본 client·legacy legacy)

- 클라: T/CLIENT_SE_TEMPLET_POTEN POTEN_PASSIVE_4040101(별빛의 궤적-EX5호 40405 등, 조건2135 기본기 치명·내 턴, 25%, SeCoolTurn1)은 NSETT_AUTO_ALLY_ONE·AutoTargetId 5, EnforceAutoTargetId 4. AUTO_SKILL_TARGET Id5 = IsAllyOneNotSelf → NKM:7566-7568 시전자 제외, 결과가 0명이면 이전 목록 유지(7758-7763), 단일 대상은 후보 2명 이상일 때만 ArrayIndex(7170-7175). 적 대상 Id4는 생존 적 무작위(기존과 같음).
- UI 문자열(SI_POTEN_DESC_JOURNEY_SCENARIO_01_HARD_CRITICAL3)은 «무작위 아군»이라고만 적혀 있으나 코드가 우선임.
