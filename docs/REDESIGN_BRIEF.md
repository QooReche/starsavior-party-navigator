## 3. 문제점 (사용자 지적, 재설계 이유)
1. **보유 구원자로 거르면 「시뮬 없음」** — 대표 240 스테이지 × 상위 팀만 사전 계산했기 때문.
2. **게임 업데이트마다 1시간+ 사전 계산** — 지속 불가.
3. **「클리어 0%·전멸 100%」만 나옴** — 아군을 Lv200·장비 없음으로 고정 → 대표 파티 약 68% 가 「추천 유보」. 무엇으로 깨라는 답이 안 됨.
4. **사람마다 레벨·장비가 다르다** — 반영 방법 없음.

## 5. 합의된 새 방향 (설계 확정 전)
- **사용자 PC(브라우저)에서 즉시 계산** — 사전 계산 폐지, 업데이트 때 데이터 파일만 교체.
- **단순 계산 + 시뮬 혼합**: 모든 후보 팀은 단순 계산(적 HP 를 몇 턴에 깎나 vs 몇 턴 버티나 → 클리어 여부·필요 전투력·약점 한 줄)으로 즉시 순위, 상위 3~5팀만 시뮬로 확인(쿨타임·트리거·도발·보스 우선 쫄몹·브레이크).
- **입력은 전투력 숫자 하나가 기본**(레벨·장비·육성 합친 값). 장비는 직업별 평균 세팅 자동, 입력 전투력에 맞춰 늘리고 줄임. 입력 없으면 「스테이지 권장 전투력만큼 키움」 가정. 역보정 표 적용. 구원자별 레벨·각인·전투력은 「내 구원자」 서랍의 **선택 입력**.
- **결과는 「쾌적 1안 + 차선 2~3안」** 맨 위. 0% 여도 「전투력 약 ○○면 깸」·부족한 점(광역 없음/힐러 없음/쫄몹 남음).
- 수동 서순 최적화는 뒤로(수동이 나아지는 팀 273팀 중 19팀). **맨 마지막**에 스타세이비어 공식 UI 분위기로 화면 조정.
