## 1. 효과 적중 vs 효과 저항 (디버프 성공률)

### 1.1 공식 [데이터] DB 「효과 적중」 탭 (ver 2.50, 2026-10)
1. **발동 판정**: 스킬에 적힌 확률(예: 레이시 궁 75/85/100%)로 먼저 판정. 일부 효과는 "대상마다 N% 판정" 추가. 아군 대상 효과·적중 판정 없는 효과는 여기서 끝.
2. ⓐ = 시전자 효과 적중 − 대상 효과 저항 + 상성 (유리 +30%, 불리 −30%, 질서↔혼돈은 서로 +30%)
3. ⓑ = 시전자 절대 적중 − (대상 절대 저항 + 역상성 절대 저항[시전자가 속성상 불리할 때만])
4. 최종 확률:

| 조건 | 최종 |
|---|---|
| ⓐ > 0 이고 ⓑ > ⓐ | ⓑ |
| ⓐ < 0 이고 ⓑ > 0 | ⓑ |
| ⓐ > 0 이고 ⓑ < 0 | min(ⓐ, 100% − \|ⓑ\|) |
| 그 밖 (ⓐ = 0 정확히 포함) | ⓐ (ⓐ=0이면 ⓑ>0이어도 0%) |

- 기본값(모든 구원자): 효과 적중 100%, 효과 저항 0%, 절대 저항 20%.
- **적(적 정보에 실린 적 전부) 절대 저항 0% → 상한 없음, ⓐ 그대로.** 구원자 대상(PvP, 또는 적이 구원자에게 걸 때) 최대 80%.
- 예: 적중 100%, 대상 저항 30%·절대 저항 20% → ⓐ 70, ⓑ −20 → min(70, 80) = 70%.
- 출처: https://starsavior-databook.pages.dev/#hit

## 3. 방어·난수·치명·관통 (피해식 확인)

### 3.1 전체 순서 [데이터] (ver 2.50) https://starsavior-databook.pages.dev/#dmg
1. 기본 = (공×계수 + 생×계수 + 방×계수) × (1 + 속도/100 × 속도계수) × 1.85 — **기존과 동일 확인**
2. 전체 대상 스킬 ÷4 (대상 수 무관, 1명 남아도 ÷4). 지속·즉발 피해는 안 나눔
3. 대상 생명력 비례 추가 피해 있으면 더함(÷4 적용, ×1.85 미적용)
4. 수호(피해 분담) 비율만큼 먼저 떼어감
5. × (1 − 방어율), **방어율 = 방어/(방어+3000) × (1 − (관통 − 대상 관통 저항))**, 0 미만이면 0. PvP는 3000 대신 300. **관통 저항이 관통보다 크면 방어율이 커짐**(관통 0, 관통저항 20% → 방어율 ×1.2)
6. × (1 + 증가 합 − 감소 합), 감소 합 최대 50%, 증가 합 상한 없음
7. × 전투력 보정(아군 피해율) × **난수 0.95 ~ 1.0499 (0.01% 단위)**
8. 대상 "생명력 비례 피해 상한" 있으면 자르고 소수점 버림, 최소 1

- 증가 합 항목: 상성 ±5%(유리 시 "상성 피해 증가" 스탯 추가), 스킬 레벨업 피해 증가, 노바 버스트 +15%, 피해 증가 버프, 조건부 패시브, 대상 강화/약화 개수 비례, 카운터 +10%, 대상 클래스·속성별(속성 스택 1%/스택, 최대 5), 스킬 종류·단일/전체별(지속 피해 제외), **치명 시 (공격자 치피 − 대상 치명타 피해 감소, 0 미만은 0)**, 브레이크 대상 피해 증가, 공격 타입(참격·타격·원소·정신·공허)별 피해 증가.
