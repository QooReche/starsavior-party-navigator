# 강제 탐색 연출 그림(`assets/forced/`)

«후보 전체 훑기»에 들어갔을 때만 쓰는 그림임. 평소 화면은 이 폴더를 받지 않음(훑기에 처음 들어갈 때 한 번 받음).
폴더를 통째로 빼도 화면은 동작함: 그웬 길은 CSS 밤하늘 바탕만 보이고, 신분증 사진은 나오지 않음.

화면 쪽 설명(상태·문구·시험)은 [fullscreen_measure_1121.md](fullscreen_measure_1121.md)의 «강제 탐색» 절에 있음.

## 파일

| 파일 | 쓰는 곳 | 만든 방법 |
|---|---|---|
| `scene.webp` (1800×600) | 그웬 길 배경 한 장 | 받은 배경 그림을 크기만 줄임 |
| `scene_narrow.webp` (800×555) | 폭 760px 이하의 그웬 길 배경 | 같은 그림에서 가로 17~65% 구간(의자~광장)만 잘라 줄임 |
| `gwen_back.webp` (424×520) | 배경 앞에 선 뒷모습 그웬(머리~허벅지) | 받은 투명 그림의 여백을 자르고 위 62%만 남겨 줄임 |
| `gwen_idcard.webp` (256×256) | «관리 실패» 판정 줄의 신분증 사진(이스터에그) | 받은 그림을 크기만 줄임 |

폴더의 파일 목록은 `gwen_lane.js` `FORCED.scene` 과 같아야 함(`tests/forced_test.js` 가 확인).
오염 SD 그웬 8장은 2026-11-22 에 없앴음 — 그웬은 화면에 한 곳에만 나옴([gwen_stage.md](gwen_stage.md)).

## 다시 만들기

```
python -X utf8 tools/build_forced_art.py --gen-dir <원본 그림 폴더>
```

원본 이름: `lavistar_ruin_bg_1.png`(배경), `gwen_back_illust_1.png`(뒷모습), `gwen_idcard_illust_1.png`(신분증 사진). 같은 입력이면 같은 결과가 나옴.

## 그림 바꿔 끼우기

- **배경**: 새 그림을 같은 이름으로 두고 위 명령을 다시 돌림. 가로세로 비율이 3:1 이 아니면 `forced.css` 의 `--fx-ar`(넓은 화면 3, 좁은 화면 1.44)도 맞춤. 좁은 화면용 자르는 구간은 `tools/build_forced_art.py` 의 `NARROW` 임.
- **뒷모습 그웬**: 새 투명 그림(전신)을 같은 이름으로 두고 같은 명령을 돌림. 위에서 얼마나 남길지는 도구의 `BACK_KEEP`(지금 0.62 = 머리~허벅지 중간)임. 도구가 찍어 주는 가로÷세로 값이 달라지면 `forced.css` `.fx-gwen` 의 `aspect-ratio`(지금 424/520)를 맞춤. 크기는 `--fx-gs`(띠 높이 대비, 지금 0.84), 가로 자리는 `--fx-gx`(인물 가운데, 넓은 화면 66%·좁은 화면 82%)임.
- 움직이는 층(안개 2겹·재·불씨·고리 빛·주기 노이즈)은 그림이 아니라 `forced.css` 의 CSS 임.

## 출처

- 사이트 운영자가 그림 생성 도구로 만든 임시 그림임. 정식 그림으로 바꿀 예정임. 원본 PNG 는 저장소에 넣지 않음.
- 외부 사이트에서 받은 그림은 없음.
