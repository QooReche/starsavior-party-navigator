# 강제 탐색 연출 그림(`assets/forced/`)

«후보 전체 훑기»에 들어갔을 때만 쓰는 그림임. 평소 화면은 이 폴더를 받지 않음(훑기에 처음 들어갈 때 한 번 받음).
폴더를 통째로 빼도 화면은 동작함: 그웬 길은 CSS 밤하늘 바탕만 보이고, 신분증 사진은 나오지 않음.

화면 쪽 설명(상태·문구·시험)은 [fullscreen_measure_1121.md](fullscreen_measure_1121.md)의 «강제 탐색» 절에 있음.

## 파일

| 파일 | 쓰는 곳 | 만든 방법 |
|---|---|---|
| `scene.webp` (1800×600) | 그웬 길 배경 한 장 | 생성 배경 그림을 크기만 줄임 |
| `scene_narrow.webp` (800×555) | 폭 760px 이하의 그웬 길 배경 | 같은 그림에서 가로 17~65% 구간(의자~광장)만 잘라 줄임 |
| `gwen_back.webp` (271×520) | 배경 앞에 선 뒷모습 그웬(머리~허벅지) | 생성 알파 잡음을 정리한 뒤 여백을 자르고 위 62%만 남겨 줄임 |
| `gwen_idcard.webp` (256×256) | «관리 실패» 판정 줄의 신분증 사진(이스터에그) | 생성 그림을 크기만 줄임 |

폴더의 파일 목록은 `gwen_lane.js` `FORCED.scene` 과 같아야 함(`tests/forced_test.js` 가 확인).
오염 SD 그웬 8장은 2026-11-22 에 없앴음 — 그웬은 화면에 한 곳에만 나옴([gwen_stage.md](gwen_stage.md)).

## 다시 만들기

```
python -X utf8 tools/build_forced_art.py --gen-dir <원본 그림 폴더>
```

원본 이름: `lavistar_ruin_bg_1.png`(배경), `gwen_back_illust_1.png`(뒷모습), `gwen_idcard_illust_1.png`(신분증 사진). 같은 입력이면 같은 결과가 나옴.

## 그림 바꿔 끼우기

- **배경**: 새 그림을 같은 이름으로 두고 위 명령을 다시 돌림. 가로세로 비율이 3:1 이 아니면 `forced.css` 의 `--fx-ar`(넓은 화면 3, 좁은 화면 1.44)도 맞춤. 좁은 화면용 자르는 구간은 `tools/build_forced_art.py` 의 `NARROW` 임.
- **뒷모습 그웬**: 새 투명 그림(전신)을 같은 이름으로 두고 같은 명령을 돌림. 알파 10 미만은 0, 245 초과는 255로 정리하고 중간 가장자리 투명도는 보존함(승인 그웬 빌더와 같은 기준). 위에서 얼마나 남길지는 도구의 `BACK_KEEP`(지금 0.62 = 머리~허벅지 중간)임. 도구가 찍어 주는 가로÷세로 값에 맞춰 `forced.css` `.fx-gwen` 의 `aspect-ratio`를 출력 파일의 실제 크기(지금 271/520)로 맞춤. 크기는 `--fx-gs`(띠 높이 대비, 지금 0.84), 가로 자리는 `--fx-gx`(인물 가운데, 넓은 화면 66%·좁은 화면 82%)임.
- 움직이는 층(안개 2겹·재·불씨·고리 빛·주기 노이즈)은 그림이 아니라 `forced.css` 의 CSS 임.

## 출처

- codex 내장 image_gen 으로 만든 정식 그림(2026-11-23)임. 원본 PNG 는 저장소 밖에 보관함. «정식»은 사이트 채택본이라는 뜻이며 게임사의 공식 원화가 아닌 생성 팬 그림임. 원 캐릭터·디자인의 권리는 원 권리자에게 있음.
- 배경은 `5e05a3f`의 채택 원본 `lavistar_ruin_bg_1.png`를 직접 참조해 하늘 위주로 편집했음. 행성·비스듬한 궤적을 없애고, 균열·금빛 파편·붉은 보라색 공허가 드러나는 방패 고리와 유리처럼 갈라지는 하늘을 넣었음. 폐허 실내·의자·작은 책상·곰인형·유럽풍 도시·기마상 광장 구도를 유지했음. 뒷모습 그웬은 승인 등신대 `tools/gwen_art/masters5/st_point.webp`의 외형·화풍과 공식 카드 `assets/savior/gwen_art.webp`의 의상을 기준으로 했으며 임시본은 자세만 참조했음. 신분증은 `506b228^`의 옛 임시 사진을 직접 참조해 베레모·셔츠·넥타이·재킷을 갖춘 과거 모습으로 맞췄으며, 승인 등신대는 얼굴·화풍에만 참조했음.
- 전체 프롬프트·참조 목록은 [forced_art_prompts.json](../tools/forced_art_prompts.json). 최초 4회·그웬 수정 2회에 이번 하늘 편집 1회(재시도 없음)를 더해 누적 7회 생성했음. 알파 합성으로 배경 제거를 확인했으며 미세 잡음은 빌더에서 정리함.
- 원본 크기는 배경 2172×724(3:1), 뒷모습 1024×1536 RGBA, 신분증 1254×1254임. 배포 배경은 넓은 화면 120,884바이트·좁은 화면 65,180바이트, 4파일 합계 222,732바이트임. 기존 `NARROW`·`BACK_KEEP`·인물 위치·표시 높이를 유지했음.
- PM 검수 수정(2026-11-23): 내장 image_gen 국소 편집으로 왼쪽 귀걸이를 지웠고, 옛 신분증을 직접 참조해 과거 복장·낡은 흑백 사진 질감을 복원했음. 이전 원본은 `*_v1.png`로 보관하고 `compare.png`·`layout_review.png`를 다시 만들었음.
- 하늘 재검수(2026-11-23): 이전 배경 원본은 `lavistar_ruin_bg_v1.png`로 보관했음. 고리 범위는 원본 기준 대략 가로 18~62%·세로 5~32%, 중심 40%·19%이며, 큰 파손부는 가로 28~41%·세로 0~19%임. `forced.css`의 빛 두 겹은 위치·크기만 고리 파손부와 아래쪽 테두리로 옮겼음(색·불투명도·움직임 주기 유지). `compare.png`·`layout_review.png`는 왼쪽 `5e05a3f` / 오른쪽 새 그림으로 갱신했음. 정지 배치 검수는 1200·600·360px이며, 기존 600×190 배치의 세로 크롭에서는 고리 대부분이 잘림. 배경 비율·장면 위치를 유지하라는 범위에 따라 크롭은 바꾸지 않았음. 검수 시트는 움직임·빛·안개를 제외한 배치 확인용임.

## 재조사 배경(준비 중)

- 내장 image_gen으로 밤의 탐정 사무실을 2회 생성했음(해상도 재시도 1회). 강제 탐색 원본 `lavistar_ruin_bg_1.png`의 화풍·도시·금빛 방패 고리를 직접 참조했음. 프롬프트·참조·대략 좌표는 [recon_art_prompts.json](../tools/recon_art_prompts.json)에 기록했음.
- 원본·검수본은 저장소 밖 `recon` 보관 폴더에만 둠. 두 생성 출력은 2172×724였고, 2차 네이티브 원본을 보존한 채 `recon_office_bg_1.png`를 Lanczos 보간으로 3072×1024로 확대했음. 네이티브 3K 생성본은 아님. 검수 WebP는 `recon_office_preview_1800x600.webp`와 `recon_office_preview_narrow_800x555.webp`임.
- 전체 그림 기준 빈 사진 4칸 중심은 (가로%, 세로%) 위 (30.9, 28.3)·(37.7, 28.3), 아래 (30.9, 48.8)·(37.7, 48.8)임. 아치창 범위는 가로 57~84%·세로 0~70%, 고리 중심은 (70.3, 28.6), 범위는 가로 62.1~78.5%·세로 23.4~33.8%임.
- 좁은 검수본은 가로 28.125~76.172%를 잘랐음. 사진 4칸을 보존했으며 창·고리 오른쪽 일부와 스탠드는 잘림. 배포용 자산·CSS 중첩·화면 연결은 만들지 않았고 실화면 연출도 미검수임.
