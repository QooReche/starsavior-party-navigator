## 1. 전투 기본 규칙

### 1.1 파티/포지션 [확인] NW
- 4인 턴제. 슬롯 배열: 후열, 전열, 전열, 후열 (영문 가이드는 "1~2열 전열, 3~4열 후열"로 표기).
- 구원자 1명을 리더로 지정, 리더 속도 +10.
- PVE 적 단일 공격: 80% 전열, 20% 후열. 디펜더가 있으면 높은 확률로 디펜더를 우선 공격.
- 코스모 게이트는 파티 2개를 요구(GC, 공지).

### 1.2 속성 상성 [확인]
- 속성 5종: 태양, 달, 별, 질서, 혼돈. 태양 -> 별 -> 달 -> 태양 순으로 유리. 질서와 혼돈은 서로 유리. (NW)
- 수치(NW): 불리한 대상 RESIST = 피해 +5%, 효과 적중 +30%, 강인도 피해 +1 / 유리한 대상 WEAK(상성 유리 쪽이 맞는 쪽) 표기가 대상 기준이라 헷갈림.
- DB 계산기(공격자 기준으로 정리, 더 명확): 속성 상성 유리 +5% / 불리 -5% 피해(피해 증가 합에 가산), 카운터 +10%, 노바 버스트 +15%. 효과 적중은 상성 유리 +30%(불리하면 -30%+역상성 절대 저항). 유리 속성 공격 시 강인도 피해를 줄 수 있고 불리 속성은 강인도 피해 불가로 읽힘(NW: "강인도 피해를 줄 수 없음"). 출처: DB 계산기(index.html), NW.
- 배율 자체는 작다(5%). 실질 가치는 (1) 강인도 깎기=브레이크, (2) 효과 적중 30%. 게임조선도 "상성 피해로 강인도를 빨리 깎는 것이 핵심"(GC).
- 주의: 일부 영문 가이드(mumuplayer)의 "솔라 파티 vs 태양 보스" 같은 예시는 상성 순환과 모순됨. 신뢰 낮음.
- 상성표 대응(구원자 a 값은 로컬 데이터 `a`와 동일 5종): 
  | 공격 속성 | 유리(강인도 깎기 가능) | 불리 |
  |---|---|---|
  | 태양 | 별 | 달 |
  | 별 | 달 | 태양 |
  | 달 | 태양 | 별 |
  | 질서 | 혼돈 | 혼돈 |
  | 혼돈 | 질서 | 질서 |
  (질서-혼돈은 서로 유리이자 서로 불리인지: NW는 "서로에게 유리"로만 적음. 불리 쪽도 대칭으로 보이나 [추정].)
- 코스믹(nm 표기 등) 구원자는 속성 무관하게 강인도를 쉽게 깎는다는 설명(레이시): GC [확인]. 최대 강인도 일반 3, 코즈믹 5 (NW).

### 1.5 속도/턴/게이지/궁극기 [확인] DB 계산기, NW
- 행동 게이지 10,000이 100%. 필요 틱 = (10,000 - 현재 게이지) / 속도. 가장 짧은 틱만큼 흘려보내 100%인 유닛이 행동, 행동 후 0. 속도·게이지 동률이면 목록 위쪽 먼저.
- 구원자 기본 속도 100 (아세라 기준 스탯). 리더 +10.
- 스킬 3종: 기본기/특수기/궁극기. 자원 없음, 특수기·궁극기는 쿨타임(NW). 별도 궁극기 게이지는 없음(턴 기반 쿨타임). 노바 포스: 특수기/궁극기 사용 시 획득, 4개 소모해 노바 버스트(다음 스킬 피해 +15%, 강인도 피해 증가·회복).
- 브레이크: 강인도 0이면 받는 피해 증가(DB: 피해 감소 합에 -15% 항목), 일반/정예/보스는 행동 게이지 0으로 초기화되고 1턴간 반격·선제방어 불가. 브레이크 상태 대상은 자기 다음 턴 시작에 강인도 전회복. 브레이크 포인트: 기본 1, PVE 보스 3, 3개 모이면 브레이크 스킬 발동(NW).

### 1.5b 피해식 요약 [확인] DB 계산기(index.html 규칙 설명)
- 기본 피해 = 스킬 계수 x 공격력 등(스킬 계수 `cf`가 DB main.json sk에 있음. 예 "공격력x65%"), 방어율 = 방어력/(방어력+3000)(PvP는 300), 증가 합(가산, 상한 없음) x 감소 합(가산, 최대 50%), 전체 대상 스킬은 /4, 치명타 시 공격자 치명 피해 - 대상 치명 피해 감소, 지속 피해(연소 공격력x20%, 출혈 x25%, 빙결 x15%+속도-3%, 중독 생명력x5%)는 /4 없음/치명 없음.

### 1.6 버프/디버프/CC [부분 확인]
- DB `gloss`(상태 효과 사전, main.json의 gloss/dict.eff): 강화/약화/속성 스택 등 분류(k). 예 냉각(달 속성 스택): 태양 속성에게 피해 +1%, 최대 5중첩. 구원자 스킬별 부여 효과 목록(`sk[].ef`, `gloss.us`)은 로컬에 이미 있음.
- CC(기절/빙결/침묵 등)의 구체 규칙표(저항 판정 외)는 못 찾음 [미확인]. 효과 적중 판정은 DB에 규칙 있음: 구원자 기본 효과 적중 100%, 효과 저항 0%, 절대 저항 20%, 상한 100%-대상 절대 저항, 적중이 대상 저항+80% 넘으면 더 올려도 무의미.
- 영문 공략의 역할 프레임(강화/탱커/서포터/컨트롤러)은 일반론이라 규칙으로는 쓸모 낮음.

- 보스별 상세 패턴(패시브 효과 텍스트)은 DB foe.js 의 스킬 `sk`(`d1`,`ef`,`gl`)에 있음. 요약 안 했음. 점수화에는 "전체 공격 비중", "공격 종류" 정도만 필요.

### 2.3 일반 PvE 적 속성 분포 [확인] DB foe.js (적 속성 집계)
- 작전(일반/어려움): 거의 전부 혼돈 적(어려움 별부스러기 요새에 별 1체). -> 작전은 질서 속성이 유리. 역할은 스트라이커/캐스터/레인저/어쌔신/디펜더 혼재.
- 성간 회랑: 혼돈이 대다수(3368/3388), 별·달 소수. 
- 일일 재화 던전: 도시 순찰=태양+질서(별 유리), 거점 조사=별+질서(달 유리), 유적 탐사=달+질서+혼돈(태양 유리). 
- 장비 탐사: 단일 속성 보스(태양/달/별).
- 플래시 포인트(10종): 보스별 속성 혼재 (태양/혼돈/질서/별/달). 보스별 `fx` 고정 보너스 2개(예: 방어력 +30%, 치명타 확률 +30%).
- 큐브 팰리스: 혼돈 13 + 질서 3 (전부 타격 종류 일부 확인).
- 적 데이터 조회 한계: 길드 던전, 여정 전투, 메인 스토리, 기간 한정 이벤트 스테이지 적 정보는 DB에 없음(DB 안내문).

## 3. 추천 파티 사례 (구조화 가능한 것)

### 3.1 GC 게임조선 [확인, 2025말~2026초, 다소 오래됨]
- 기본: 레이시를 먼저 넣고 나머지를 딜러로. PvE 딜러 4 또는 딜러 3+서포터 1. 디펜더는 비추천(생존/보호 낮음).
- 딜포터(메인 딜러 강화+자체 딜): 세이라, 샤를, 다나. 힐 서포터: 프레이(단일힐+디버프 해제 / 전체힐+보호막), 세르팡(전체힐 + 스킬 피해 무효).
- 작전 후반/고난도: 레이시 + 딜러 2 + 힐 서포터.
- 코스모 게이트(파티 2개): 레이시는 한쪽만. 속성 상성 최우선. 기본 구성 "레이시+상성 딜러 3" / "상성 딜러 4" / "상성 딜러 3+딜포터 1".

### 3.2 OS oslink 티어표 (구원자, 속성, 직업) [확인, 상업 블로그]
- T0 레이시(혼돈/유랑자), 세이라(질서/타격자), 샤를(태양/타격자). T1 다나(별/마법사), 카르멘(달/방어자), 루나(질서/마법사), 스마일(별/유랑자), 아세라(달/타격자). T2 프레이, 키라, 에핀델, 트리쉬, 릴리, 에드, 하레, 엘리사. T3 타냐 페트라 리디아 루 뮤리엘 셀판 벨라 베스타. T4 클라리사 클레아 날 안나 스칼렛 마르실르.
- 편성 예: 내구형(카르멘+레이시+엘리사+샤를), 속공 섬멸형(세이라+스마일+아세라+다나), 방치형(루나+스마일+샤를+아세라). 용도: 내구형=고난도 보스, 속공형=경쟁/고속, 방치형=잡몹.

### 3.3 BS 블루스택(2026-06 기준) [확인, 역할 서술 위주]
- S+: 에밀리, 샤를(하트 오브 모나스티르), 아세라(왈츠 오브 스타라이트), 세이라, 루나. S: 뮤리엘, 벨 리스, 엘리사, 프레이(노블 프린세스), 클레어, 힐데.

## 4. 로컬 구원자 데이터와 결합해 점수화하려면 필요한 규칙 데이터 제안

로컬에서 이미 쓸 수 있는 것: 구원자 r(6역할), a(5속성), k(4공격종류), g(등급), st(스탯: 생명력/공격력/방어력/속도/치명/효과 적중/효과 저항/절대 저항/강인도), sk(스킬: 대상 tg 적 단일/적 전체/아군 단일/아군 전체/자신, 행동 act 공격/비공격, 계수 cf, 효과 ef, 레벨별 lv, 부여 상태 gl), nm(코스믹 여부, 현재 모두 False라 판별에 쓸 수 없음 -> 코스믹은 `cc` 필드나 별도 목록 필요 [추정]).

필요 규칙 데이터(우선순위 순). 아래 1~3은 DB/NW에서 이미 구조화 가능:
1. 상성표(5x5, 유리=+1/불리=-1/중립=0) + 상수(피해 +-5%, 효과 적중 +-30%, 유리 시만 강인도 피해 가능). 출처 NW/DB. 즉시 작성 가능.
2. 콘텐츠별 적 프로필 테이블: 콘텐츠 id -> 적 속성 분포, 역할 분포, 공격 종류, 단일/전체 공격 비율, 적 수(웨이브), 적 스탯(HP/공격/방어/속도/강인도), 제한 턴. 원천 DB foe.js(u/s/g 구조) 변환 스크립트 필요. 코스모 게이트 11보스는 이미 확보.
3. 시즌 보너스 테이블: 코스모 게이트 보스x시즌 -> (속성 또는 역할 조건, 효과, 값). 값 'ex/pick' 의미 확인 필요. 플래시 포인트 보스별 fx(고정 적 버프).
4. 스킬 태그화: 로컬 sk 문장을 파싱해 "전체 공격/단일 공격/힐/보호막/디버프 해제/방어 감소/버프 제거/침묵/도발/궁극기 쿨 감소/강인도 피해량/속도 증가/행동 게이지 조작/은신/부활/반격·선제방어" 같은 기능 태그 + 수치. DB의 `gloss`(상태 효과 사전 19개 이상 + 종류 k)가 어휘 기준이 됨. 이게 점수화의 핵심이며 현재 가장 큰 공백.
5. 역할 요구 규칙(휴리스틱, 출처 GC/BS): 파티당 딜러 3~4, 서포터 0~1, 디펜더 비추천(광역 적에서), 코스모 게이트는 2파티 간 구원자 비중복, 코스믹(레이시)은 1파티 제한 등. 숫자 가중치는 근거가 약하므로 설정 파일로 두고 사용자 조정 가능하게.
6. 전투 시뮬/근사 모델용: 행동 게이지 공식(확인됨), 피해식(확인됨), 브레이크 규칙(확인됨). 완전 시뮬 대신 "N턴 내 강인도 파괴 가능성 + 누적 피해 근사" 점수가 현실적. 적 패턴(패시브)은 텍스트라 수동 태깅 필요.
7. 커뮤니티 티어 데이터(선택): 출처 간 불일치가 커서 가중치는 작게. 정답 데이터가 아닌 보조 신호.
8. 시즌 구원자 보유/출시 정보: DB `rel`(출시일, 상시풀 여부)로 "내가 가진 구원자" 필터 보조 가능.

못 구한 것(추가 조사 필요): 속성/종류별 세부 CC 규칙, 공격 종류 상성, 레벨별 보스 패턴 설명의 요약, 코스모 게이트 이외 콘텐츠 주기, 길드 방어전/메인 보스 적 정보, 적 스탯 열 이름 대응, 전투력 보정 수치표(DB 계산기 안 상수), 공식 티어/추천 편성.
