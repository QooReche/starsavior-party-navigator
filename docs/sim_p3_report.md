# 전투 시뮬레이터 P3 검증 보고 — 적 행동·생존·확률 엔진 (2026-10-20, codex 2·3차 검토 + 사용자 관찰 반영판)

## 0. 한 줄 요약
이제 시뮬레이터가 **적도 때리고, 아군이 쓰러지고, 회복·보호막·도발·수호가 실제로 작동**하며, 같은 전투를 수백 번 굴려 **「클리어 확률·처치 턴·누가 먼저 쓰러지나」**를 낸다. 결과의 큰 방향 — **4딜덱은 화력 1위로 가장 빨리 끝내지만 버티기는 약하고, 서포터 편성은 늦게 끝나는 대신 훨씬 오래 버틴다** — 는 커뮤니티 평가와 맞는다. 다만 **장비 없는 Lv200 기준**이고 **「적 공격에도 아군과 같은 ×1.85 피해식」·「전투 시작 때 쿨타임이 꽉 참」이라는 두 가정이 클리어 확률을 크게 좌우**하므로, 숫자 자체는 실측으로 보정하기 전까지 **팀끼리 비교용**으로만 봐야 한다. 웹 화면(`index.html`)과 웹 화력 지표(`data/damage_index.json`)는 바뀌지 않았다.

> 이 판은 codex 2차 검토 차단 7건, 3차(재검토) 차단 2건(아래 7절)을 고치고 **사용자 관찰 「오토 아군은 보스를 먼저 친다」를 기본 규칙으로 바꾼 뒤(3.6절) 전부 다시 잰 값**이다.
> - 첫 판에서는 서포터의 주 회복 스킬이 실제로 회복하지 않았다(데이터의 별도 회복 계수 칸을 안 읽음) → 고침.
> - 2차 판에서는 프레이 궁극기의 「별 속성이면 회복량 증가」가 전원에게 붙어 25% 과다 회복, 세르팡 〈스킬 피해 무효〉가 엉뚱한 아군에게 감 → 고침.
> - **보스 우선 규칙 때문에 보스+쫄몹 스테이지(매니저 그레고리 Ⅰ)의 결과가 크게 바뀌었다**: 쫄몹(카지노 픽서)이 오래 살아 계속 때려 정석 90% → 24%, 서포터 3 100% → 56%, 4딜덱 100% → 93%.

## 1. 무엇이 생겼나 (쉬운 말)
| 전 (P2 까지) | 지금 (P3) |
|---|---|
| 적은 가만히 맞기만 함. 「10턴 동안 얼마나 때리나」만 계산 | 적이 스킬(기본기·특수기·궁극기, 쿨타임, 전체 공격)을 쓰고 효과 문장(자기 강화·약화 부여·연쇄 피해·면역·스킬 피해 무효 등)도 실행 |
| 아군 HP 없음 → 디펜더·서포터 가치가 안 보임 | 아군 HP·사망(쓰러지면 행동·협공 모두 끝), 스킬 회복(프레이·엘리사·웨딩 카르멘 등)·보호막·부활·도발·수호(대신 맞기)·피해 감소·회피, 피격 시 발동 효과 |
| 확률은 평균값으로 뭉갬(치명 15% → 피해 15% 가중) | 치명·약화 성공·협공·적의 공격 대상·피해 난수(95~105%)를 **실제로 굴림**. 같은 시드면 같은 결과, 판 수(`n_runs`)만큼 반복 |
| 처치 턴 1개 숫자 | 클리어/전멸/시간 초과 확률(95% 범위 포함), 처치 턴 중앙값·10~90% 범위, 구원자별 피해 비중·받은 피해·회복량·쓰러질 확률·처음 쓰러질 확률, 적별 준 피해(모든 웨이브 합) |
| P2 에서 미룬 것 | 카운터 +10%(같은 칸 스킬), 리더 속도 +10(아군·적), 적 피해 감소 기믹·스테이지 효과(받는 피해 −15% 등) 반영 |

쓰는 법: `python -X utf8 -I tools/sim_damage.py simulate --party gwen,fei,professor-m,amora --leader 0 --stage "cosmo/길레/길레 2단계" --runs 200` (형식은 `battlesim/README.md`).

## 2. 시험한 조건
- **구원자**: Lv200·공명 10단계·각인 0·**장비·잠재력·여정 없음**(코스모 게이트·플래시 포인트 고정 조건과 같은 기준. 작전·회랑은 실제 육성과 다를 수 있음). 오토 전투(노바 버스트 안 씀).

**읽는 법**
- **사용자 관찰이 시뮬에 그대로 나온다(보스와 쫄몹이 같은 웨이브일 때)**: 그레고리 Ⅰ 에서 단일 전용 편성은 보스 우선 규칙이면 쫄몹(픽서 2마리)이 준 피해가 3,155 → **21,247(약 7배)**, 받은 피해 +30%, 쓰러지는 아군 1.05 → 2.67명, 클리어 98% → **55%**. 작전 8-8 도 쫄몹 피해가 481 → 1,984(약 4배).
- **광역 편성은 같은 상황에서 쫄몹을 같이 깎는다**: 보스 우선일 때 쫄몹 피해 비중이 단일 전용보다 낮다(그레고리 Ⅰ 31% 대 36%, 작전 8-8 49% 대 63%). 다만 이 광역 편성은 장비 없는 기준 전체 화력이 낮아 그레고리 Ⅰ 을 어느 규칙으로도 못 깨고(보스에 전원 쓰러짐), 처치도 단일 편성보다 늦다 — 「광역이면 무조건 유리」가 아니라 「쫄몹이 보스와 같이 나오는 곳에서 단일 전용 편성의 약점이 커진다」로 읽어야 한다.
- **보스가 마지막 웨이브에 따로 나오면(작전 8-16, 회랑 28) 규칙 차이가 작다**: 쫄몹 웨이브는 어차피 쫄몹만 있어서 같다. 보스 웨이브에서는 보스 우선이 오히려 받은 피해를 줄였다(보스를 빨리 잡음).
- 대표 표(3.1)에서 그레고리 Ⅰ 의 모든 팀 클리어가 내려간 것이 이 규칙 때문이다(최저 HP 규칙이던 2차 판: 4딜덱 100%, 정석 90%, 서포터 3 100%).

### 3.7 실행 시간
판 1개 1.4~10.7ms(중앙 4.3ms). 200판 = 약 0.3~2초. 위 9 스테이지 × 6팀 × 200판 + 민감도 = 약 90초. 추천 상위 10팀 재시뮬(설계 4절, 후보당 64판 + 최종 400판)도 스테이지 하나에 수 초 수준.

## 5. 아직 안 되는 것(미지원)과 이유
실행 전 검사(`unsupported.static`)는 이제 **효과의 뜻까지** 본다: 숫자 속성이 없는데 엔진이 이름으로 모르는 효과, 엔진이 반영하지 못하는 속성 이름(반격 확률 등), 효과 뒤에 해석 못 한 문구(「피해 제한 0%」 등), 「이번 스킬에만」 보정 중 엔진이 모르는 종류를 모두 미지원으로 적는다.
