# 추가 턴·대상 연쇄·조건 경계·파쇄 연계 확인

PC 클라 빌드 26610546. `check_build.py`로 설치본과 디컴파일 DLL 8개 해시 일치를 재확인했음.
아래 경로는 비공개 `starsavior-static-data` 기준임. 원문 표·계정 결과는 공개 저장소에 복사하지 않았음.

## 1. 추가 턴과 화면 TURN — 클라와 같음

- `decompiled/NKM/NKM.decompiled.cs:4996-5000`: 추가 턴은 다음 전역 턴에 사용할 예약을 설정함.
- 같은 파일 `12289-12309,12396-12408`: 예약된 추가 턴의 게이지를 채우고 일반 턴 유닛 선택기에 넣음.
- 같은 파일 `13880-13891`: 전역 턴을 먼저 1 올린 다음 그 선택기를 호출함. 추가 턴 제외 분기는 없음.
- `decompiled/NKC/NKC.decompiled.cs:14593,99414-99423`: 화면 TURN은 전역 턴 값을 그대로 표시함.
- 엔진 `Battle.run`의 `global_turns` 증가·추가 턴 소비·행동 집계는 유지했음. 협공/추가 발동은 선택된 추가 턴과 다름.
- 편애의 마녀 아세라의 실제 스킬로 추가 턴을 발생시켜 전역 턴 1~4·제한 종료·행동 합계 4·양수 진행도를 검사했음. 추가 턴을 세지 않는 결함은 시험이 검출했음.

## 2. 대상 공격력 연쇄 — 클라 확인, 공통 파서 미지원 수정

- `decompiled/NKM/NKM.decompiled.cs:4730-4735`: `NSETT_TARGET`는 각 피해 수신자의 지정 능력치, `NSETT_SELF`는 시전자의 지정 능력치를 사용함.
- `tables/SE_TEMPLET_SKILL_2.json:18814-18829`: 이벤트 보스 섀도우 미나 기본기는 대상 공격력 50%임. 같은 표 `1063-1077`의 공용 효과도 대상 공격력 20%임.
- 현재 `rawdata/foe.js`에는 해당 이벤트 콘텐츠·적이 없어, 이 스킬이 자신 공격력으로 잘못 변환됐다고 확인하지 않았음. 존재하지 않는 적/스테이지를 임의로 추가하지 않았음.
- 공통 파서는 대상 공격력·방어력 연쇄를 해석하지 못했으므로 수신자별 현재 능력치로 처리하게 했음. 시전자의 공격력 보정은 수신자에게 넘기지 않으며 일반 연쇄의 시전자 피해 증가·방어식은 유지함. 기존 대상 생명력 경로는 유지했음.
- 합성 대상 공격력 1,000·2,000, 첫 대상 공격력 증가 30%, 계수 50%의 고정 연쇄는 각각 650·1,000임. 일반 연쇄·기존 미지원 선택지도 검사했음. 실제 이벤트의 전투 편성 연결은 현재 데이터에 없음.
- 기대값 엔진은 적의 공격력·능력치 효과 상태를 모델링하지 않아 대상 능력치 연쇄를 미지원으로 보고함. 공통 파서 확장으로 예외가 나지 않는지도 검사했음. 실제 추천 화면의 확률 엔진은 위 식을 사용함.

## 3. 대상 HP 조건 — 달라서 고침

`decompiled/NKM/NKM.decompiled.cs:2191-2198,10480`에서 현재·최대 HP를 각각 float32로 변환해 나누고 결과도 float32로 반환함.
`decompiled/NKM.Templets/NKM.Templets.decompiled.cs:43125-43174`의 이상·이하 조건은 이 값을 double로 승격한 `int(HP비율×10000)` 비교임.
엔진의 실수 비율 직접 비교를 바꿨음. HP 25,010/100,000은 클라에서 2,500으로 절삭되므로 25% 이하에 해당함.
독립 리뷰에서 float32 변환 누락을 발견해 반영했으며, HP 50,009,999/100,000,000의 반대 방향 경계도 검사했음.
경계 양쪽·0·100%·여러 대상의 두 번째 대상·legacy를 검사했음. 자신 HP·엄격 초과/미만 조건까지 같은 식이라고 확대하지 않았음.

## 4. 자신 미보유 효과 중첩수 — 달라서 고침

`decompiled/NKM.Templets/NKM.Templets.decompiled.cs:42252,42265,42427-42450`:
이름별 해당 효과가 존재하고, 일반 효과이거나 지정 중첩수가 0 이하이거나 레벨이 정확히 같으면 조건을 막음.
엔진의 이상 비교·후속 합산 검사를 이름별 동등 비교로 바꿨음. 서로 다른 1·2중첩을 3으로 합산하지 않음.
`BUFF_TEMPLET.IsLevel`은 `tools/build_buff_count.py`로 가공했음. 동명 충돌·미등록 효과의 IsLevel은 미확인이므로 기존 중첩 판정을 유지함.
현재 구원자 사용 여부와 무관하게 부재·미달·일치·초과·여러 이름·일반 효과·0 지정·legacy 경계를 검사했음.

## 5. 편애의 마녀 아세라 ↔ 구원자 길레 — 사유 누락 수정

- `tables/SE_TEMPLET_SKILL_1.json:41726-41729`: 아세라 궁극기의 자신 파쇄 3턴.
- 같은 표 `13053-13075,13393-13398`: 구원자 길레의 파쇄 아군 대상 서곡·행동 게이지·속도 지원.
- `tables/Plain/AUTO_SKILL_TARGET_TEMPLET.json:652-655`: 자동 대상 10201은 파쇄 보유 필터임.
- 생성기에 자신이 얻는 상태→그 상태인 아군 대상 지원 후보 추출을 추가했음. 이번에 요청한 쌍만 반영하고 시너지·근거·HTML을 재생성했음.
- 같은 방식의 다른 누락 후보는 **티리아 ↔ 구원자 길레의 파쇄 연계** 1쌍임. 목록만 보고하며 반영하지 않았음.
