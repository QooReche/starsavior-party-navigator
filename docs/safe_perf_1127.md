# 11/27 결과 불변 최적화

- 기준: 배포 커밋 `1197383`, `perf/safe-1127`, 같은 Windows PC. 계정 자료 없이 공개 표준 육성·합성 입력만 사용했음.
- `tools/bench_safe_perf.py --capture`는 기준 커밋에서만 한 번 정답을 만들고 기존 파일을 덮어쓰지 않음. 기존 동결값은 갱신하지 않음.
- 3개 편성·고정 시드로 달/태양 회랑, 길드 30112 전 단계, 코스모, 칸 미상, 소환, 웨이브 전환, 브레이크 라운드 경계를 검사함. 응답(벽시계 제외)·내부 상태·난수 상태를 float.hex 기반 해시로 대조함. 행동·진행도·소환·웨이브 전환이 실제 발생했는지도 검사함.
- 속도는 데우기 1회 뒤 5회 중앙값, 표의 단위는 ms/판임. 각 표는 직전 항목과 비교함. 무거운 시험·벤치는 순차 실행했음.
- `tools/bench_safe_daily.js`는 `git show 1197383`으로 고정 구현을 읽어 합성 작업자의 최종 팀·점수·표준오차·서명까지 대조함. 데우기 1회 뒤 3회 중앙값이며 실제 전투 실행 속도와 구분함.

## 측정·검증

전후 엔진은 `--compare <직전 커밋>`으로 번갈아 5회 실행했음. 각 실행에서 준비 1회·8판 측정, 중앙값(ms/판). 기준선 전체 시험은 재부팅 전 중단본 대신 배포 당시 결과를 사용했음.

| 항목 | 달100 전→후 | 태양200 전→후 | 태양250 전→후 | 길드 30112/7 전→후 |
|---|---:|---:|---:|---:|
| E1 | 10.697→9.985 | 21.704→19.859 | 21.989→19.415 | 15.222→13.148 |

- E1: 42판 응답·내부/난수 상태 동일, 관련 시험 4파일 통과. 옛 정렬 구현으로 되돌린 변이와 생존 목록 역순 변이가 각각 새 시험에 잡혔음. 칸 미상 생존 시 원래 목록 순서, 사망 뒤 알려진 칸 정렬, 같은 칸 안정 순서·소환·웨이브·덱 교체를 검사했음.
