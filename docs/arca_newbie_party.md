# 뉴비용 파티 편성 공략 요약 (arca.live/b/starsavior/174374805, 작성 2026-06-20, 수정 2026-10-08)
개인 의견 글(추천 18). 아래는 구조화용 요약(원문 아님).

## 규칙
- 편성은 전열/후열. PvE 에서 전열은 피격 확률이 높고, 전열에 디펜더가 있으면 약 95% 로 디펜더만 맞는다.

## 편성 유형 (슬롯 순서 = 글의 표기 순서)
1. 정석: 딜러 / 디펜더 / HP 높은 서포터 / 딜러. 디펜더가 피격 흡수, 서포터는 남은 전열.
2. 노탱 레이시: 자율 / 레이시 / 자율 / 자율. 레이시의 조건부 피격 HP 회복으로 초반 잡몹은 무시. 후반 보스에는 약해 디펜더를 키워야 함.
3. 노탱 웨르멘(웨딩 카르멘): 자율 / 맞아도 되는 딜러(레이시 또는 페이) / 은신(그웬 또는 키라) / 웨딩 카르멘. 카르멘의 딜러 보호 스킬에 의존. 어그로가 불안정해 전열에 은신 캐릭터 필요(그웬이 키라 상위호환, 피격에도 은신 유지). 고점 높고 리트 가능성 있음. 페이=회피+반격, 레이시=HP 회복 기믹.
4. 딜링 디펜더: 자율 / 공격력 세팅 디펜더 / 자율 / 웨딩 카르멘. 카르멘 보호 효과를 디펜더가 받음. 매우 튼튼하나 편성·세팅 제약 큼(디펜더 다수가 HP/방어력 계수 스킬).

## 엔진 반영 메모
- 구원자 키/역할 의존: 레이시, 페이, 그웬, 키라, 웨딩 카르멘(카르멘 변형, party_reco 로스터의 '카르멘(이터널 프로미스)' 와 같은지 확인 필요), 디펜더.
- 전열/후열 위치와 은신·보호·피격 효과 태그(synergy_tags 결과)를 쓰면 위 4유형을 템플릿으로 구현 가능.
