## 2. 효과 적중 / 저항 (DC: app.js 1369–1400 `calcHit`, index `#e-flow #e-key #e-myth`)
```
발동 = 스킬 확률 × (대상마다 N% 판정)          # 아군 대상·적중 판정 없는 효과는 여기서 끝
a = 시전자 효과 적중 − 대상 효과 저항 + 상성(유리 +0.30 / 불리 −0.30, 질서↔혼돈 서로 +0.30)
b = 시전자 절대 적중 − (대상 절대 저항 + (시전자 불리일 때만) 역상성 절대 저항)
if (a>0 and b>a) or (a<0 and b>0): f = b
elif a>0 and b<0:                 f = min(a, 1−|b|)
else:                             f = a          # a==0 이면 b>0 여도 0
최종 = clamp(f, 0, 1) × 발동
```

- 데이터 줄 표기: `{효과 적중 판정}`, `(대상마다 75% 판정)`, `N% 확률로`.

## 5. 회복·보호막·도발·피해 감소 (DC app.js 1360 `calcHeal`, #d-heal)
