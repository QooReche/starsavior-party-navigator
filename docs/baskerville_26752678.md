## 입력과 적용 범위

`tools/build_foe_cosmo.py --tables <26752678 추출 T>`로 `data/foe_cosmo_extra.json`을 생성했음. 비공개 원문 표는 넣지 않았음. 표 경로는 `E:/AI_mk2/rebuild_26752678/T`, 코드 경로는 `E:/AI_mk2/decomp_26752678/set10/clean`을 사용했음. 아래 N은 해당 경로의 `NKM/NKM.decompiled.cs`임.

설치본 buildid는 26752678이며 `set10/dll` 10개와 설치 DLL의 SHA-256이 전부 일치했음. 비공개 저장소 `check_build.py`는 그 저장소의 옛 26610546 디컴파일과 다르다고 보고했음. 해당 옛 코드를 근거로 쓰지 않고 사용자 지정 재추출본을 대조했음. 외부 저장소 갱신·메인 작업 트리 수정·push는 하지 않았음.

효과마다 실행 담당은 하나임. `cosmo` 효과는 파서의 일반 효과 대신 Controller가 처리함. 일반 SE는 엔진이 실행하고, 부여 메타데이터는 독립 객체·강제 적용·분류·플래그를 설정하는 데만 씀. 활성 스킬 효과는 선택된 카드의 `semantic_lines`를 사용해 교체 전후 특수기 효과가 함께 실행되지 않게 했음. 슬롯 상태는 전투 Unit에 두며 공유 FoeDef는 바꾸지 않음.

## 클라 근거와 경계

- HP 감소는 새 최대 HP를 초과하는 현재 HP만 절삭하고 해제 자체로 회복하지 않음(N:3070-3081,4493-4494).
- IsUniqueID는 반복마다 독립 버프 객체를 만들며 개별 수명·순서를 보존함. SpecificBuffCount는 IsLevel 중첩수가 아니라 적 전체의 버프 객체 수를 셈(N:4505-4524,5663-5678,16396-16405).
- MyEffectiveHit의 Caster는 공격자이고, 같은 피격 안에서 SE를 실행할 때마다 조건을 다시 확인함(N:7999-8006,10356-10377,16103-16116,16374-16405,16526-16528). 엔진의 일반 조건 일괄 판정은 바스커빌 외에는 그대로 유지했음.
- FixStats 속도 0이어도 직접 게이지 증가는 받음. 보유자 자기 턴 종료 기준이며 부여한 턴은 차감하지 않음(N:5111-5116,12426-12446,13962-13969,4004). SuperArmorDamageBan은 이름과 별개로 강인도 피해를 차단함(N:17206-17210, CLIENT_BUFF_TEMPLET.json:51018). 두 공통 규칙의 기본은 off이며 바스커빌 코스모 전투에서 켬.
- BI_CHANGE_SKILL은 슬롯을 즉시 교체하여 유지함. RESET은 쿨 0, 다음 자신/적 턴 시작의 SE가 +1하며 현재 스킬 최대 쿨을 넘지 않음(N:2922-2933,3084-3090,2412,3105-3109).
- BOSS_7의 최대 중첩 0은 무제한임(N:4445). 조사 문서와 달리 현재 문자열 원문 `hard/STRING_COMMON.json:114693-114695`의 `Keys` 배열에 패시브3·BOSS_7 이름 **끝나지 않는 사냥**이 있음. 이름이 없는 추출본에만 가명을 사용함.
- 강제 기절은 그룹 1001·기절 면역을 우회하며 SE의 EffectHitCheck=false를 버프 기본값보다 우선함(N:4318,4407,6112).
- BI_HEAL은 당시 최대 HP 기준이며 주는/받는 회복량 보정을 적용함(N:2186-2188,5533-5543).
- UAT_ELEMENT는 `hard/STRING_COMMON.json:52816-52818`의 SKILL_TAG_ELEMENT «원소 피해»를 기존 공격 태그 표기 방식에 맞춰 «원소»로 표시했음.

## 병합과 검증

로더는 콘텐츠 키가 아닌 `(콘텐츠, 탭, 스테이지)` 중복을 검사함. 기존 데이터북 스테이지가 우선이며 조각의 u/s/x·소환 인덱스는 오프셋을 적용함. 자동 대상·강제 적용 정보는 스킬 안에 있어 전역 인덱스에 의존하지 않음. aux는 채택된 스테이지와 그 소환 그룹만 가져오며 반복 병합은 아무것도 추가하지 않음.

`tests/baskerville_client_test.py`는 변환 문법·HP 상한/낮은 HP·마지막 해제/회복 감소·객체 개수 배율·강제 기절·교체 왕복·두 턴 지속·처치/사망·다중 조각 인덱스·격전 자료 보존을 검사함. `--mutations`는 교체/개수 배율/개별 해제/쿨 증가/독립 객체/속도 고정/강인도 플래그/HP 절삭/SE 재판정/강제 적용을 각각 제거하여 10개 모두 단언 실패를 확인하고 원복함.

기존 격전 빌더 재실행 결과 u/s/x/g/aux/unmodeled가 저장된 격전 조각과 같았음. 옛 판 재현 스킬 63/63·효과 줄 134/134·상태 설명 78/78을 유지했음. 캐시 고정 해시 3건과 골든 구원자 65·파티 150·스테이지 팀 10건도 일치했음. 공통 규칙의 기본값은 기존 동작이라 quick·guild_sim은 재계산 없이 이유를 적어 도장만 갱신했음.

독립 리뷰는 고정 커밋 범위 `751d5add..f4c52927`을 대상으로 했으며 확정 결함 없음, 해당 스냅숏의 전용 시험 8개 통과를 별도로 확인했음. 이후 시험을 확대했음. 전체 실행 결과는 HISTORY의 이 작업 절에 기록함.
