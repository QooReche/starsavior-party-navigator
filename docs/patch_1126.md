## 후속 리뷰 — 시즌 선택과 동작 등록

설치본 26935738·디컴파일 DLL 10개가 일치함을 다시 확인했음. 이번 변경은 기존 동작의 선택 경로를 옮긴 것이며 전투 규칙·기본값·확률을 새로 추정하지 않았음. 칸 연결은 현재 `tables/UNIT_TEMPLET_BASE2.json:116063,118643`, 6스킬은 `SKILL_TEMPLET_2.json:9595`, SE는 `SE_TEMPLET_SKILL_2.json:17224`부터의 기존 정의와 대조했음. 수정 전후 생성기로 현재 클라를 읽어 자동 대상 1,021개·과거 보스 정의 5개의 출력이 같음을 확인했음.

길드의 코스모 의존은 실행 경로가 아니라 `build_simpack.FIXED`를 재사용한 추출기에서 생겼음. `guild.client_waves`는 일반 적/보관 정의를, BFB는 보관 전용 자산을 읽으며 현재 코스모 사본을 읽지 않음. 이를 명시적 공용 입력 목록으로 분리하고 JSON 내용 해시·공통 직렬화를 적용했음. 같은 JSON을 다른 공백/키 순서로 써도 통과하며 실제 값 변경은 오류로 남음. 의존 검사 캐시도 엔진 캐시 초기화에 포함했음.

`ec7224c`와 수정본을 같은 공개 표준 편성(gwen/fei/professor-m/amora), seed 7, 2판, 타임라인 포함으로 비교했음. 시간 필드·자료 버전만 제외하고 실행 중 미지원 진단도 포함한 결과 해시가 119/119 같았음.
