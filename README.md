# 스타세이비어 파티 편성 네비게이터 (베타)

내 구원자로 스테이지를 깰 파티를 찾습니다. 추천 팀·클리어 가능성·턴·위험 구원자를 확인하세요.

[사이트 열기](https://QooReche.github.io/starsavior-party-navigator/)

1. **내 정보 불러오기**에서 PowerShell 명령을 복사해 실행합니다.
2. 관리자 확인 [예] 후 게임에 로그인하고, 로비가 뜨면 도구 창에서 엔터를 누릅니다. 게임이 켜져 있으면 완전히 종료 후 재실행하세요.
3. 사이트가 자동으로 열리며 반영됩니다. 콘텐츠·스테이지를 고르고 **추천 편성 보기**를 누르세요.

자동 반영이 안 되거나 다른 기기로 옮길 때는 바탕화면 `내정보.json`을 **파일 선택**으로 불러오세요. 게임 업데이트 직후에는 도구 갱신이 필요할 수 있습니다.

게임 파일은 건드리지 않고, 내 PC에서만 해독합니다(관리자 확인 1회). [추출 도구](https://github.com/QooReche/starsavior-myinfo). 내 정보는 이 브라우저에 저장하며, 자동 반영 주소의 해시는 서버로 전송되지 않습니다.

**링크 복사**는 내 구원자 수치를 기본으로 포함해 다른 사람에게 편성 조언을 받을 수 있습니다. **내 구원자 수치 포함**을 끄면 조건만 공유합니다.

**클리어 추천 육성**을 켜면 덜 키운 보유 구원자를 목표치까지 키웠다고 치고 클리어 가능한 편성을 따로 보여 줍니다. 기준선보다 낮은 항목만 올립니다(스킬은 7 이하인 스킬만 10, 장비 +15 프리셋, 스텔라 아카이브 주력 950 미만이면 1,250 등). 이미 넘은 항목·패시브·미보유 구원자는 그대로 둡니다. 카드에는 항목마다 «지금 → 목표»와 늘어나는 전투력을 칩으로 표시합니다.

새 형식 내 정보를 불러온 뒤 콘텐츠를 실행하면 **스타링크 슬롯 추천 → 슬롯 추천 계산**을 사용할 수 있습니다. 실행한 스테이지만 비교하며 현재 슬롯 수 안에서 넣기·빼기를 제안합니다. **확인 부족**은 미평가 또는 불확실한 결과입니다. 실제 교체에는 쿨다운이 있습니다.

비공식 팬 도구 · 게임사와 무관 · 시뮬은 실제와 다를 수 있음

11/12 업데이트: 신규 구원자 길레·편애의 마녀(아세라)를 포함한 11/12 패치를 반영했습니다. 격파된 아군도 다음 자기 턴에 행동하도록 클라 코드 기준을 적용했고, 빠른 계산을 다시 보정했습니다. 길드 방어전은 시즌 종료로 미오픈이며 시뮬 표는 새 시즌 자료 반영 때 다시 계산합니다. 실제 플레이 대조 전이라 결과가 다를 수 있습니다.

큰 보스전은 편성에 따라 시뮬이 비관적이거나 낙관적일 수 있습니다. 이미지 권리는 원 권리자에게 있습니다.
