# 스타세이비어 파티 편성 네비게이터 (시험판)

콘텐츠(작전·성간 회랑·플래시 포인트·코스모 게이트 등)와 스테이지를 고르면, 그 적의 속성 분포에 맞는 4인 파티(전열 2/후열 2)와 브레이크 스킬, 대체 구원자를 보여 주는 개인용 도구입니다. 점수는 **자동 계산한 참고용**이며 검증된 공략이 아닙니다.

## 전투 전망 읽는 법 (2026-10 추가)
추천 팀 위의 「전투 전망」은 전투 시뮬레이터로 같은 전투를 여러 번(확정 후보는 200판) 돌려 본 결과입니다. **장비·잠재력·여정 없는 Lv200·공명10 기준 모델**이라 실전 숫자가 아니라 **팀끼리 비교하는 참고값**입니다.
- **클리어 확률**: 턴 제한 안에 모든 적을 쓰러뜨린 판의 비율. 「10판 중 n판」으로도 적었고, 막대 위 옅은 띠는 반복 시뮬의 퍼짐(95% 범위)입니다. 등급: 안정(90% 이상·전멸 5% 미만) / 보통 / 불안 / 위험.
- **처치 턴**: 클리어한 판에서 마지막 적을 쓰러뜨린 시점의 가운데 값과 보통 범위. 「모델 기준 턴」= 속도 100 구원자가 한 번 행동하는 시간이라 게임 화면의 턴 숫자와 다를 수 있습니다.
- **먼저 쓰러지는 구원자**: 가장 자주 먼저 쓰러지는 구원자와 그 시점. **전멸 확률**이 10% 이상이면 빨간 「전멸 위험」 칩이 붙습니다.
- **카드 아래**: 그 구원자의 피해 비중(막대)과 쓰러질 확률(점).
- **추천 순서**: 클리어 확률을 먼저 보고(5%p 단위로 묶음), 비슷하면 처치 턴이 빠른 팀. 전멸 위험을 화력으로 상쇄하지 않습니다.
- **가정 한 줄**: 「적 공격에도 ×1.85 피해식」·「전투 시작 때 쿨타임이 꽉 참」 같은 아직 실측하지 못한 가정을 바꾸면 1위가 바뀌는지 보여 줍니다(펼치면 표).
- **오토 / 수동**: 기본은 오토 전투. 수동을 고르면 노바 버스트와 대상 지정을 쓰는 정책 4가지 중 가장 나은 것으로 다시 계산해 「오토 대비」 차이와 **서순(스킬 순서 예시)** 표를 보여 줍니다. 서순은 그 정책으로 싸운 대표 1판의 기록이지 최적 순서는 아닙니다. 팀은 오토 기준으로 고른 그대로입니다.
- **시뮬 없음**: 보유 구원자를 바꿔 미리 계산하지 않은 팀이 되면 「근사 점수만 · 시뮬 없음」, 대표 스테이지가 아니면 「시뮬 미계산 스테이지」(스테이지 목록의 ◆ = 결과 있음), 시뮬레이터가 아직 못 다루는 적 기믹이면 「계산 불가」로 표시하고 숫자를 지어내지 않습니다.
- 계산 범위·판 수·가정 = `docs/sim_p4_report.md`. 페이지는 웹 주소(또는 로컬 서버)로 열어야 결과를 불러옵니다.

## 계산 방식
- DB 티어(가이드 DB의 PVE 티어) + 속성 상성 + 주 사용 콘텐츠 여부 + 팀 기능 태그(힐·보호막·딜 버프 등)
- 규칙값(가중치, 상성, 콘텐츠, 브레이크 스킬, 뉴비 편성 유형)은 `party_contents.json` 에서 고친다. 가중치는 임의값이다.
- 구원자 기능 태그는 스킬 텍스트에서 키워드로 뽑은 것이라 오판이 있다(`docs/synergy_tags_review.md`).

## 최근 반영
- 대체 후보: '이 구원자만 빠지고 나머지 3명을 유지했을 때' 팀 점수가 높은 순(직업 무관). 보유 체크로 실제 빼 본 결과와 맞는다.
- 시너지 쌍(`pairs`): 웨딩 카르멘 + 코즈믹 아세라는 서포터 2명이어도 허용한다(점수 가산은 없음, 상성 등이 맞을 때만 선택).
- 디펜더는 2번째부터 감점, 상성 가중치는 보스 콘텐츠(코스모 게이트·플래시 포인트)와 일반 콘텐츠를 구분.
- 웹 페이지의 보유 구원자·브레이크 스킬 선택은 브라우저 localStorage 에 자동 저장된다(서버 전송 없음).
- 스테이지 이름 끝의 로마 숫자(Ⅰ, XVI 등)는 1, 2, 16 으로 표시한다. 전투력 패널티는 '옵션'(기본 접힘)이며 추천 편성에는 반영하지 않고 배율만 보여 준다(편성을 바꾸면 전투력도 달라지므로).
- 가중치 검증 메모: `docs/weight_check.md`(근거가 약해 일부만 반영, 오토 전투 기준은 추정).

## 스킬 연계 시너지와 구조도
- `data/synergy_pairs.json`: 구원자 스킬 텍스트에서 자동 추출한 연계 1,120쌍(부여→소비, 버프 증폭, 생존, 쿨감·행동 게이지, 속성 공유). 강도 1~3, 신뢰(확인/추정)와 근거 문장 포함. `docs/synergy_pairs_review.md` 에 검수 결과.
- 팀 점수에 `party_contents.json` 의 `synergy` 가중치(유형별 x 강도 x 신뢰, 합계 상한)로 반영된다. 가중치는 임의값이고 '추정' 쌍은 0.6배.
- 웹 페이지 하단 구조도(Cytoscape.js, `lib/`): 추천 파티의 연계 / 구원자 중심 / 전체 지도. 선을 누르면 근거 스킬 문장.
- **게임 업데이트 후:** `python -X utf8 -I tools/update.py <databook main.json>` 한 번이면 태그·연계·분류를 다시 만들고 변경 요약(신규 구원자, 바뀐 쌍)을 출력한다. 자동 추출이 틀렸거나 직접 넣고 싶은 연계는 `data/synergy_overrides.json`(ignore/set/add)에 적으면 재실행해도 유지된다.

## 스테이지 적 기믹
- `data/stage_gimmicks.json`(스테이지별 기믹 유형·심각도 3,596개)와 `data/gimmick_rules.json`(유형 44종: 이름, 구원자 태그 선호/기피, 필요 슬롯)을 스킬 원문 분석(`tools/build_gimmicks.py`, 결과 검토는 `docs/gimmick_review.md`)으로 만들었다.
- 개인 점수: 스테이지 기믹에 유리한 스킬 구조(예: 보호막 파괴/방어 관통, 단일 대형 타격)는 가산, 불리한 구조(예: 다단 히트)는 감산. 팀 점수: 기믹 대응에 필요한 슬롯(예: 보호막 파괴 담당 + 후속 폭딜)을 파티가 채우면 가산. 가중치는 `party_contents.json` 의 `gimmick`.
- 영향 방향은 대부분 추정이다(피격이 타수 단위인지 스킬 단위인지 원문에 없음). 태그가 많은 구원자(에핀델 등)가 유리해지는 편향이 알려져 있다.
- `tools/update.py` 가 foe 데이터를 갱신하면 기믹도 다시 만든다(`tools/build_gimmicks.py`, `tools/pack_gimmicks.py`).

## 화력 지표(시뮬레이터)
- `tools/sim_damage.py`(행동 게이지 방식 이벤트 시뮬레이터, 설명·검증은 `docs/sim_report.md`)가 구원자별 턴당 기대 피해(단일/광역)와 아군 피해 증가를 계산하고 `data/damage_index.json` 에 압축한다. 팀 화력 점수(0~10)는 `party_contents.json` 의 `damage` 가중치로 파티 점수에 더한다.
- Lv200·공명10·장비 없음 기준 **상대 비교용**이며 인게임 실측이 아니다. 적의 공격·생존·힐·보호막, 브레이크, 장비·아르카나는 미반영, 협공 규칙은 추정이다.

## 사용
```
python -X utf8 -I party_reco.py 작전 --stage "SECTOR 1-1"          # 콘솔
python -X utf8 -I party_reco.py "코스모 게이트" --stage 길레 --owned wedding-carmen,fei,...
python -X utf8 -I build_party_html.py                              # ..\release\party_preview\index.html 생성(단일 HTML)
```
`-I` 는 스크립트 폴더를 import 경로에서 빼므로 `build_party_html.py` 는 스스로 경로를 추가한다.

## 폴더
- `data/` 입력 데이터: `db_tier.json`(티어·주 사용 콘텐츠), `synergy_tags.json`(기능 태그), `foe_stages.json`(스테이지별 적 정보 4.6MB), `kinds.json`(어나더/코즈믹), `savior_reco.json`·`saviors_index.json`(구원자 목록·이미지 경로)
- `assets/` 직업·속성 아이콘, 브레이크 스킬 원형 이미지
- `tools/build_foe.py` 데이터북 `foe.js` -> `data/foe_stages.json` 재생성
- `docs/` 조사 자료(전투 규칙·콘텐츠 정리, 브레이크 스킬, 뉴비 편성 공략 요약, 태그 검수표)

## 출처와 주의
- 구원자·적·티어·편성 정보: 가이드 DB(starsavior-guide.github.io), 팬 데이터북(starsavior-databook.pages.dev), 나무위키, 아카라이브 글, 제3자 DB(브레이크 스킬 효과). 데이터북 재사용은 사용자가 허락받은 것으로 확인되었다(2026-10-19).
- 직업·속성 아이콘과 브레이크 스킬 이미지는 게임 리소스다. 사용 허락은 사용자가 확인했다고 함(2026-10-19).
- 구원자 초상화·일러스트는 가이드 DB 사이트에서 내려받아 줄여서 `assets/savior/` 에 담았다(`tools/fetch_images.py`, 사용자가 이미지 저장을 허락). 웹 페이지(`index.html`)는 이 상대 경로를 쓴다.
- 게임 화면·실전 편성 효과는 검증하지 못했다.

## 재생성 메모(구)
- `synergy_tags.py <databook main.json>`: 데이터북 `data/main.js` 를 JSON 으로 푼 파일이 필요하다.
- `crop_break_icons.py`: 인게임 브레이크 스킬 스크린샷을 `break_ref/7~11.png` 로 둔다(특이점 관측, 스타피어서, 큐브 과부하, 행성 정화, 차원 강습 순).
- `tools/build_foe.py`: 데이터북 `data/foe.js` 를 `tools/raw/` 에 내려받아 둔다.
