## 용량과 notes

한도는 `budget.json` 한 곳임. 공통 art3 배정 1,450,000 + art4 쌍 500,000 + 깜빡임 175,000 + art5 1,700,000 = **3,825,000B**임. 중복 배정하지 않았음. 배포 파일 113개 **3,158,015B**, 여유 **666,985B**임.

notes.webp의 140,000B 예외를 없앴음. `sleeve8.encode`를 손실 WebP quality 95 / method 6으로 바꿨으며 **57,416B**임. 전체 파일 공통 **80,000B 이하**임. 450/220/330ms, loop=1, 알파와 소매 연결을 유지함. 원화·정지 PNG·눈 패치의 픽셀 보존은 유지하고 손실 동작 WebP는 작은 RGB 압축 오차를 허용함. 정지 PNG는 소매 밖 완전 동일, WebP는 알파 동일·보호 영역 평균 오차·양팔 연결을 검사함. `_tmp/direct-c/notes-compare.png`에서 240px 실제 크기로 원화 합성/압축 결과를 직접 비교했으며 얼굴·손·소매에서 눈에 띄는 차이는 관측하지 못했음.

art6.md의 art8 무손실·예외 한도 기록은 당시 경과이며 현재 정책은 이 절이 대체함. 생성 횟수·원화 provenance는 바뀌지 않았음. `gwen_art8_test.py`에 예외 키 부재 검사를 넣었으며 예외를 되살리면 실제 시험이 실패함을 확인하고 원래 바이트로 복원했음.

## 연결과 수명

- `ux_ui.js`의 GWEN_SCENES에 SD 2차 10종·깜빡임 7종, st_* 10종·깜빡임을 연결했음. 기존 confident/thoughtful/notes 교체분도 기존 경로로 사용함. 등신대 동작은 1회 뒤 정지하며 별도 눈 그림이 있는 경우 눈만 깜빡임. 기존 3종은 동작 파일에 눈감기가 들어 있음.
- `gwen_lane.js`가 반반·직접 편성의 후보·대사·우선순위·말풍선·발표·이동을 관리하고, 이미지 decode/동작/깜빡임은 기존 Ux 컨트롤러가 맡음. 이동 요소는 한 개이며 예약한 길 사이에 DOM을 옮김. 다른 칸을 가로지르는 절대 좌표는 사용하지 않음.
- 편성 길은 몸체 88px/휴대폰 72px에 말풍선 전용 34px를 별도로 예약함. 본체는 PC 80px, 휴대폰 64px임. 결과 등신대는 1200px 이상에서 240px로 표시함. 길은 클릭을 받지 않고 본체 단추만 클릭을 받음.
- 걷기 60px/s·달리기 240px/s, 한 이동 구간 최대 600ms, 도착 후 150ms 착지임. 먼 칸은 여러 구간으로 나눔. 400px 이하에서는 속도와 요청 거리를 절반으로 줄임. 휴대폰 홈은 이동 없음. 화면 밖 실행은 퇴장을 기다리지 않고 진행 자리로 전환함.
- 상황 후보는 직전 두 그림을 제외함. 두 후보뿐이라 모두 제외되면 직전 그림을 제외하며, train/charge 등 지정 그림 하나인 상황은 그 그림을 사용함. 반응 대사 4초 쿨다운, 말풍선 실제 표시 6초 간격·2.5초 표시, 그림 반응 1.5초임. 계산 중에는 조작 반응을 받지 않음. 결과 발표 여부와 화면 폭별 그림 선택은 별도로 저장함.
- 클릭 shy→sulk→cry 뒤 10초 무반응, 10초 이상 클릭이 없으면 새 순서임. 빈 칸 20초·방치 60초·wake를 연결했음. quiet는 로컬 저장하며 짧은 반응·이동을 끄고 계산·결과·오류 그림을 유지함. reduced-motion은 이동·뛰기·동작 WebP를 끄며 계산 그림은 20초마다 교체함. 숨김/화면 밖에서는 보이는 시간만 계산하는 시계와 이동을 정지함.
- 자동 추천은 기존 상황 흐름을 유지하고 결과 후보에 새 등신대를 섞음. 결과 확률이 같으면 방문 안에서 선택이 고정됨. 보고와 결과 그림이 동시에 나오지 않게 했으며, 걷기는 transform 이동 구간으로 바꿨음. 기존 클릭·wake·reduced 계산 순환도 같은 규칙으로 갱신했음.
