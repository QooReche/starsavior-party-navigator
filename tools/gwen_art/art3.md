# 그웬 SD 13종·깜빡임 10종

2026-11-16 그림 전용 추가임. 승인된 investigate·ready 512px를 얼굴·의상·비율·선·색의 기준으로 사용했음. 공식 자료는 울상 자세·표정·소품 근거로만 확인했음. 원 캐릭터 권리 안내는 [README](README.md)를 따름.

## 생성·채택

내장 `image_gen`, `transparent_background=true`로 13종을 각각 생성했음. 프롬프트 전체와 재생성·깜빡임 편집 지시는 [prompts3.json](prompts3.json)에 있음. cry에는 공식 울상 자세, zap에는 공식 스턴건 SD를 보조 참조로 넣었음. 나머지는 승인 SD 두 장을 직접 참조했음. 공식 원본은 보기만 했으며 이 저장소에 복사하지 않았음.

내장 도구의 생성 캐시에서 `_tmp/art3/`로 결과를 복사한 뒤 후처리했음. 생성은 비결정적이므로 채택한 `assets/ui_icons/gwen/*_512.png`와 `blinks3/*_eyes_512.png`를 보존했음. 이후 빌드는 생성 API를 쓰지 않음.

## 후처리·동작

[build3.py](build3.py)는 원본 알파의 10 미만 잡음만 없애고 245 초과를 불투명으로 정리한 뒤 가장자리 알파를 보존했음. 본체를 최대 450px에 맞춰 512px 캔버스에 놓았음. 기존 `compact_master`의 내부색·알파 팔레트 방식을 사용하고, 한도를 넘은 magnify만 FASTOCTREE 팔레트를 줄였음. 160px PNG는 기존 build2 방식으로 색을 줄이고 축소 원본 알파를 복원함.

모든 새 WebP는 160px, 4프레임, **300/200/200/300ms = 1초**임. 첫·끝 512px 프레임은 원본과 동일함. 기존 quality=88/method=6 WebP 인코더를 재사용함.

| 종류 | 동작 | loop |
|---|---|---:|
| cry | 한쪽 오므린 손·팔을 작게 흔듦 | 1 |
| verdict | 채찍 든 손목을 작게 움직임 | 1 |
| cheer | 든 팔을 작게 흔듦 | 1 |
| sulk | 머리를 아주 작게 돌림 | 1 |
| shy | 모은 손을 작게 움직임 | 1 |
| doze | 빵을 문 머리가 꾸벅 움직임 | 1 |
| think | 머리 위 반짝의 위치·밝기 변화 | 0 |
| magnify | 낮게 든 돋보기·손목 이동 | 0 |
| stamp | 도장 쥔 손목·도장을 작게 움직임 | 0 |
| board | 카드를 붙이는 손목 이동 | 0 |

| zap | 원본 스파크 픽셀의 밝기·청백색만 깜빡임 | 0 |

큰 자세·얼굴을 프레임마다 다시 생성하지 않았음. 신문을 내릴 때 드러나는 작은 틈은 신문 바로 위 원본 경계 픽셀을 연장했음. 실제 가려진 얼굴을 새로 그리지 않았음.

## 깜빡임·마스크

대상은 ready·welcome·investigate·files·report·think·shy·sulk·verdict·cheer임. [blink_masks3.json](blink_masks3.json)에 원본 512px 눈 주변 다각형을 저장했음. `blinks3/<name>_eyes_512.png`는 내장 도구로 편집한 감은 눈을 마스크 안에서만 가져온 512px RGBA 패치임. 패치의 알파는 이진 마스크이며 원본에 합성한 뒤 원본 알파를 복원함. 패치만 사이트에서 불러오는 구조가 아님.

512px 합성 결과와 160px `<name>_blink.png` 모두 **마스크 밖 RGBA가 원본과 바이트 단위로 같음**을 빌더·시험에서 검사함. 160px 마스크는 512px 마스크를 Lanczos로 축소한 필터 영향 범위까지 포함함. 전역 재팔레트화로 눈 밖 색이 변하지 않도록 원본 정지 PNG에 눈 패치만 합성함. 마스크 면적은 캔버스의 4% 미만임.

깜빡임은 단일 정지 PNG이며 행동 WebP의 200ms 이상 규칙을 적용하지 않음. 120~160ms 표시 시간·반복 간격은 화면 코드 작업의 범위임.

## 용량

대표 cry·zap부터 정규화·인코딩해 측정했음. cry 초기 PNG+WebP 31,362B, zap 초기 측정용 손목 동작 PNG+WebP 28,884B였음. 이후 cry 동작 영역과 zap의 최종 스파크 동작을 확정해 아래 최종 바이트가 됐음.

## 재현·검증

검증 환경: Python의 Pillow **12.3.0**, libwebp **1.6.0**. 바이트 재현은 같은 인코더 버전 기준임.

```powershell
# 커밋된 원본·눈 패치로 재현; 생성 API 호출 없음
python -B -X utf8 tools/gwen_art/build3.py --compare
# 출력 파일을 수정하지 않고 검증
python -B -X utf8 tools/gwen_art/build3.py --check
# 최초 가져오기만: 채택 원화와 눈 편집 원본을 _tmp/art3에 둔 경우
python -B -X utf8 tools/gwen_art/build3.py --import-dir _tmp/art3 --import-blinks _tmp/art3 --compare
python -B -X utf8 -I tests/gwen_art_test.py
python -X utf8 -I tools/run_tests.py
```

`_tmp/_art_compare3.png`를 `view_image`로 직접 확인했고, 실제 표시 크기 확인을 위해 행별 분할본도 직접 확인했음. 기존 7 SD·새 13종의 64·72·120·160px, 어두운 UI, 깜빡임 전후, 저장된 동작 3번째 프레임을 포함함. 재생성된 verdict의 소품과 핀 방향·투명 가장자리·축소 표정 가독성을 확인했음. 시트는 커밋하지 않음.

자산 시험 7개를 통과했음. 새 원본·정지·동작의 존재/크기/알파/파일 한도, 프레임 차이/1초/loop, 동작 부위 제한, 눈 마스크 밖 동일, 59개 원본·출력·패치의 빌드 전후 SHA-256 동일을 검사함. 기존 빌더 build2·build_ready도 새 단일 한도로 통과했고 기존 자산 바이트는 변경되지 않았음.

되돌림 검출: ready_blink.png를 ready.png로 바꾸면 `Blink is identical to open image`에서 실패했음. 눈 밖 (1,1) 픽셀을 바꾸면 `Pixels outside eye mask changed`에서 실패했음. 두 변조 모두 백업에서 원복했음.

`python -X utf8 -I tools/run_tests.py` 최종 결과는 **186통과/실패0**임. `COSMO_TABLES`가 없어 `cosmo_raid_test.test_data_matches_tables` 1건을 건너뛰었음. 기준 전체 실행은 대표 파일이 실행 중 추가되어 총량 시험만 실패(185통과/1실패)했고, 새 파일을 잠시 분리한 원래 자산 기준 시험은 2개 모두 통과했음. 최종 로그는 `_tmp/art3/final-tests.log`, 변조 검출 로그는 `_tmp/art3/mutation-identical.log`·`mutation-outside.log`임.

화면 코드·index.html은 수정하거나 재생성하지 않았음. E2E 화면 연결·재생 타이머·로딩 전후 레이아웃은 이번 그림 작업에서 검증하지 않았음. 공개 저장소에는 채택 그림·눈 패치·프롬프트·빌더·시험·문서만 포함함.
